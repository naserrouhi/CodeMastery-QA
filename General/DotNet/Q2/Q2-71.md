# Q2-71: What's DLX in RabbitMQ?

- A Dead Letter Exchange (DLX) is a special type of exchange where messages are sent when they can't be processed by a queue.

- It helps in handling failed or expired messages properly instead of losing them.

- Each queue can be configured with a DLX.

- The DLX then routes messages to a special Dead Letter Queue (DLQ) for further processing.

- When are messages sent to a DLX?

    1. Message is rejected (using BasicNack or BasicReject) without requeueing.
    2. Message expires due to TTL (Time-To-Live) settings.
    3. Queue limit is reached (queue is full).

- Example:

    1. Declare the DLX Exchange and Queue:

```csharp
channel.ExchangeDeclare("dlx_exchange", ExchangeType.Direct);

channel.QueueDeclare("dlx_queue", true, false, false, null);
channel.QueueBind("dlx_queue", "dlx_exchange", "dlx_routing_key");
```

    2. Configure a Main Queue to Use DLX:

```csharp
var args = new Dictionary<string, object>
{
    { "x-dead-letter-exchange", "dlx_exchange" },
    { "x-dead-letter-routing-key", "dlx_routing_key" }
};

channel.QueueDeclare("main_queue", true, false, false, args);
```

    3. Send a Message to the Main Queue:

```csharp
channel.BasicPublish("", "main_queue", null, Encoding.UTF8.GetBytes("Test message"));
```

    4. Simulate Message Failure (Send to DLX):

```csharp
channel.BasicConsume("main_queue", false, (model, ea) =>
{
    Console.WriteLine("Received: " + Encoding.UTF8.GetString(ea.Body.ToArray()));

    channel.BasicNack(ea.DeliveryTag, false, false); 
});
```
