# Q2-57: What's binary?

- Binary is a number system that uses only two digits: 0 and 1.

- It's the most basic form of data representation used in computers and digital systems.

- Computers use binary because they rely on electronic circuits that have two states: on (1) and off (0).

- Example: A binary number like 101 represents a value, just like decimal (base-10) numbers do. The binary number 101 is equal to 5 in decimal (because 1 × 2^2 + 0 × 2^1 + 1 × 2^0 = 5).
