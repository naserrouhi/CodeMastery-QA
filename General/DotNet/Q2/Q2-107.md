# Q2-107: What is SSO?

- SSO (Single Sign-On) is a system that lets users log in once and access multiple applications without re-entering credentials.

- Steps:

    1. User logs in
    2. SSO system authenticates
    3. User gets a session/token
    4. Accessing other apps

- Example:

  - Google SSO: If you sign in to Gmail, you can access Google Drive, YouTube, and Google Photos without entering your password again.
  - Corporate SSO: A company uses Microsoft Entra ID (Azure AD), so employees log in once and access Outlook, Teams, and SharePoint without multiple logins.
