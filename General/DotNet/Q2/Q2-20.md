# Q2-20: What does GroupJoin do?

- It performs a join between two collections and groups the matching elements from the second collection.

- No member of first collection will be removed, but some memebers of second collection may be removed.

```csharp
var employees = new List<Employee>
{
    new Employee { Name = "Alice", DepartmentId = 1 },
    new Employee { Name = "Bob", DepartmentId = 2 },
    new Employee { Name = "Charlie", DepartmentId = 2 },
    new Employee { Name = "David", DepartmentId = 3 },
    new Employee { Name = "Eve", DepartmentId = 1 },
    new Employee { Name = "Frank", DepartmentId = null } // No department
};

var departments = new List<Department>
{
    new Department { Id = 1, Name = "HR" },
    new Department { Id = 2, Name = "IT" },
    new Department { Id = 3, Name = "Sales" },
    new Department { Id = 4, Name = "Marketing" } // Department with no employees
};

var groupedJoin = departments.GroupJoin(employees, 
                                        d => d.Id,
                                        e => e.DepartmentId,
                                        (d, empGroup) => new 
                                        {
                                            Department = d.Name,
                                            Employees = empGroup
                                        });
```
