# Q2-78: What's the split-brain scenario?

1. Network Partition

    - A network failure divides a system into isolated groups that can't communicate with each other.

    - It’s a general issue in distributed systems.

    - Example: A RabbitMQ cluster splits into two groups due to a network failure.

2. Split-Brain

    - A consequence of a network partition where two or more nodes act as independent leaders, causing data inconsistency.

    - It happens when each partitioned group keeps working separately, leading to conflicts.

    - Example: In a RabbitMQ mirrored queue, both the primary and backup nodes think they are the leader and process messages separately.
