# Q2-82: What's AMQP?

- AMQP (Advanced Message Queuing Protocol) is an open standard protocol used for messaging and queuing.

- It defines how messages are structured and transmitted between different systems in a messaging system like RabbitMQ.

- Key Concepts:

    1. Message Broker: AMQP operates through a message broker (e.g., RabbitMQ), which routes messages between producers and consumers.
    2. Producer
    3. Consumer
    4. Queue
    5. Exchange: The exchange determines how the messages are routed to queues based on routing keys and binding rules.
    6. Binding: A rule that links an exchange to a queue.
    7. Routing Key: A key that the exchange uses to route messages to the correct queue.
