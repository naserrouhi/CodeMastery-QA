# Q2-74: How should we control requeue proccess in RabbitMQ?

1. Declare the Main Queue with DLX

    - Messages that fail move to a retry queue via DLX.
    - The retry queue has a TTL (delay) before sending the message back for retry.

```csharp
var mainQueueArgs = new Dictionary<string, object>
{
    { "x-dead-letter-exchange", "retry_exchange" }
};

channel.QueueDeclare("main_queue", true, false, false, mainQueueArgs);
channel.ExchangeDeclare("main_exchange", ExchangeType.Direct);
channel.QueueBind("main_queue", "main_exchange", "main_key");
```

2. Declare the Retry Queue with TTL

    - The retry queue holds failed messages for a delay (TTL) before retrying.
    - After TTL expires, messages go back to the main queue.

```csharp
var retryQueueArgs = new Dictionary<string, object>
{
    { "x-message-ttl", 10000 },
    { "x-dead-letter-exchange", "main_exchange" }
};

channel.QueueDeclare("retry_queue", true, false, false, retryQueueArgs);
channel.ExchangeDeclare("retry_exchange", ExchangeType.Direct);
channel.QueueBind("retry_queue", "retry_exchange", "retry_key");
```

3. Publish a Message to the Main Queue

```csharp
var properties = channel.CreateBasicProperties();
properties.Headers = new Dictionary<string, object> { { "retry_count", 0 } };

var message = "Hello, process me!";
var body = Encoding.UTF8.GetBytes(message);

channel.BasicPublish("main_exchange", "main_key", properties, body);
```

4. Consumer with Retry Handling

    - If retry limit is not reached, it sends the message to the retry queue.
    - If retry limit is reached, the message goes to a DLQ or gets discarded.

```csharp
consumer.Received += (model, ea) =>
{
    var properties = ea.BasicProperties;
    var headers = properties.Headers ?? new Dictionary<string, object>();
    var retryCount = headers.ContainsKey("retry_count") ? (int)headers["retry_count"] : 0;

    try
    {
        var message = Encoding.UTF8.GetString(ea.Body.ToArray()); 
        throw new Exception("Simulated failure");

        channel.BasicAck(ea.DeliveryTag, false);
    }
    catch (Exception)
    {
        if (retryCount >= 2) //Max retry reached
        {
            channel.BasicNack(ea.DeliveryTag, false, false); //Discard 
        }
        else
        {
            var newProperties = channel.CreateBasicProperties();
            newProperties.Headers = new Dictionary<string, object> { { "retry_count", retryCount + 1 } };

            channel.BasicPublish("retry_exchange", "retry_key", newProperties, ea.Body);
            channel.BasicAck(ea.DeliveryTag, false); // Ack to remove from main queue
        }
    }
};
```
