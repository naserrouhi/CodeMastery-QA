## Q2-15: What is a Delegate?

- It is a type that represents references to methods with a specific signature.

- It allows methods to be passed as parameters, assigned to variables, and executed dynamically at runtime.


- Example:

    - "MyDelegate" is a delegate that can reference any method that takes a string parameter and returns void.

```csharp
public delegate void MyDelegate(string message);

public class Program
{
    public static void Main(string[] args)
    {
        var del = new MyDelegate(PrintMessage);
        del("Hello, Delegate!");
    }

    public static void PrintMessage(string message)
    {
        Console.WriteLine(message);
    }
}
```

```csharp
public delegate int MathOperation(int a, int b);

public class Calculator
{
    public int Add(int x, int y) => x + y;
}

var calc = new Calculator();
MathOperation operation = calc.Add;
var result = operation(5, 3);
Console.WriteLine(result);
```


- Multicast Delegates

    - A delegate can hold multiple methods and invoke them in sequence.

```csharp
public class MyClass
{
    public void PrintMessage(string message) => Console.WriteLine($"Message: {message}");
    public void PrintUpperCase(string message) => Console.WriteLine($"Upper: {message.ToUpper()}");
}

var obj = new MyClass();
MyDelegate del = obj.PrintMessage;
del += obj.PrintUpperCase;
del("Hello!");
```


- Anonymous Methods

    - Instead of defining a separate method, you can use anonymous methods with delegates.

```csharp
MyDelegate del = delegate (string msg)
{
    Console.WriteLine(msg);
};

del("Hello from an anonymous method!");
```

- Lambda Expressions

    - Lambda expressions simplify delegate usage.

```csharp
MyDelegate del = msg => Console.WriteLine(msg);
del("Hello from a lambda!");
```


- Built-in Delegates

    1. Func Delegate (Returns a Value)

```csharp
Func<int, int, int> add = (a, b) => a + b;
Console.WriteLine(add(2, 3));
```

    2. Action Delegate (No Return Type)

```csharp
Action<string> print = msg => Console.WriteLine(msg);
print("Using Action Delegate!");
```

    3. Predicate Delegate (Returns Boolean)

```csharp
Predicate<int> isEven = num => num % 2 == 0;
Console.WriteLine(isEven(4));
```
