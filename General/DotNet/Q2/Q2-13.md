# Q2-13: Which OOP priciples do interfaces and abstract classes supoort?

- Interface

  - Encapsulation → Ensures that only the defined members are accessible.

  - Abstraction → Hides implementation details and only exposes required behavior.

  - Polymorphism → Allows different classes to be used interchangeably.

- Abstract Class

  - Encapsulation → Can enforce controlled access to data by defining members with different access levels.

  - Abstraction → Allows defining common behavior.

  - Polymorphism → Enables treating different subclasses as instances of the abstract class.
