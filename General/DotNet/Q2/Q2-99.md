# Q2-99: Make an example of Docker Concepts

practice

1. Docker Image

    - It is a pre-built package that contains the application and all its dependencies.

    - Example: Creating a simple .NET 8 web app image

        1. Create a Dockerfile:

```bash
# Base image with .NET runtime
FROM mcr.microsoft.com/dotnet/aspnet:8.0 

# Set the working directory inside the container
WORKDIR /app 

# Copy the application files to the container
COPY . . 

# Command to run the app
CMD ["dotnet", "MyApp.dll"]
```

        2. Build the image:

```bash
docker build -t myapp .
```

        3. List available images:

```bash
docker images
```

2. Docker Container

    - It is a running instance of an image.
    - Example: Running a container from the image

```bash
docker run -p 8080:80 myapp
```

    - Now the app is accessible at http://localhost:8080.
    - To list running containers:

```bash
docker ps
```

    - To stop a container:

```bash
docker stop <container_id>
```

3. Docker Hub

    - It is a cloud-based repository for storing and sharing Docker images.
    - Example: Pushing an image to Docker Hub

    1. Login to Docker Hub

```bash
docker login
```

    2. Tag the image

```bash
docker tag myapp username/myapp:v1
```

    3. Push the image to Docker Hub

```bash
docker push username/myapp:v1
```

    - Now, anyone can pull the image using:

```bash
docker pull username/myapp:v1
```

4. Docker Compose

    - It helps manage multi-container applications using a docker-compose.yml file.

    - Example: Running a .NET app with a PostgreSQL database

        1. Create a docker-compose.yml file:

```yaml
version: '3.8'

services:
  webapp:
    image: myapp
    ports:
      - "8080:80"
    depends_on:
      - db

  db:
    image: postgres
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: password
      POSTGRES_DB: mydatabase
```

        2. Run all services with:

```bash
docker-compose up -d
```

        3. Stop all services:

```bash
docker-compose down
```
