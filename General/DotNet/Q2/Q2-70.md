# Q2-70: What is Priority Queue in RabbitMQ?

- When you retry a message directly in the same queue, it goes to the end of the queue, because RabbitMQ uses FIFO by default.

- Priority queue allows messages to be processed based on their priority level.

- Higher-priority messages are dequeued and processed before lower-priority messages.

- Consumers will receive higher-priority messages first, ensuring urgent tasks are handled promptly.

- Using priorities can have a performance impact, especially with a large number of priority levels or a high volume of messages.

- If no priority is set, the message defaults to priority 0.

- Key Concepts:

    1. Queue Declaration: When declaring a queue, you must specify that it supports priorities by setting the `x-max-priority` argument.

    2. Message Publishing: When publishing a message, you can set its priority using the `priority` property in the message properties.

- Steps:

    1. Declare a Priority Queue

```csharp
var factory = new ConnectionFactory() { HostName = "localhost" };
using (var connection = factory.CreateConnection())

using (var channel = connection.CreateModel())
{
    var arguments = new Dictionary<string, object>
    {
        { "x-max-priority", 10 }
    };

    channel.QueueDeclare("priority_queue", true, false, false, arguments);
}
```

    2. Publish Messages with Priorities

```csharp
var factory = new ConnectionFactory() { HostName = "localhost" };
using (var connection = factory.CreateConnection())
using (var channel = connection.CreateModel())
{
    var queueName = "priority_queue";
    var message = "High priority task";
    var body = Encoding.UTF8.GetBytes(message);

    var properties = channel.CreateBasicProperties();
    properties.Priority = 10;

    channel.BasicPublish("", queueName, properties, body);
}
```

    3. Consume Messages

```csharp
var factory = new ConnectionFactory() { HostName = "localhost" };
using (var connection = factory.CreateConnection())
using (var channel = connection.CreateModel())
{
    var queueName = "priority_queue";
    var consumer = new EventingBasicConsumer(channel);

    consumer.Received += (model, ea) =>
    {
        var body = ea.Body.ToArray();
        var message = Encoding.UTF8.GetString(body);
        var priority = ea.BasicProperties.Priority;
        
        channel.BasicAck(deliveryTag: ea.DeliveryTag, multiple: false);
    };

    channel.BasicConsume(queue: queueName,
                         autoAck: false,
                         consumer: consumer);

    Console.ReadLine();
}
```
