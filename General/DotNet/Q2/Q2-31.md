# Q2-31: What are wildcards?

- A wildcard is a special character or symbol used to represent one or more characters in a search, pattern matching, or routing system.

- Wildcards provide simple pattern matching for filenames, SQL, and routing, while regex offers powerful and flexible text pattern matching for validation and string processing.

1. Wildcards in RabbitMQ (Topic Exchange)

    - In RabbitMQ, wildcards are used in routing keys to match multiple patterns.

        - * → Matches exactly one word.
        - # → Matches zero or more words.

    - Example:

        - A producer sends messages with routing keys:

            - logs.error.database
            - logs.info.server

        - A consumer binds a queue using a wildcard:

            - logs.*.database
            - logs.#

2. Wildcards in File Searching (Linux, Windows)

    - * → Matches any number of characters.
    - ? → Matches a single character.

    - Example:

        - file*.txt → Matches file1.txt, fileABC.txt.
        - data?.csv → Matches data1.csv, but NOT data12.csv.

3. Wildcards in SQL

    - % → Matches any number of characters.
    - _ → Matches a single character.

4. Wildcards in Regular Expressions

    - . → Matches any single character.
    - .* → Matches any number of characters.

    - Example:
        - c.t → Matches cat.
        - a.*z → Matches amazing.
