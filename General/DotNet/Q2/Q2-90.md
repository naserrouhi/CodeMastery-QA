# Q2-90: What is equivilant to Exchange, Queue and Routiung key in Kafka?

1. Exchange (RabbitMQ) → Topic (Kafka)

    - In Kafka, a topic serves the same role. producers send messages to a topic, and consumers read from it.

2. Queue (RabbitMQ) → Partition (Kafka) + Consumer Group

    - A partition inside a topic is where messages are stored.

    - A consumer group ensures that messages are distributed among multiple consumers (similar to multiple consumers reading from a RabbitMQ queue).

3. Routing Key (RabbitMQ) → Key (Kafka)

    - In Kafka, the message key is used to decide which partition a message goes to.

    - Example: If you publish a message with key="user123", Kafka will always send it to the same partition (ensuring order for that key).
