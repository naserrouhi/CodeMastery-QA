# Q2-26: What is Exclusive and AutoDelete in DeclareQueue of RabbitMQ?

1. Exclusive Queue

   - It can only be accessed by the connection that declared it.
   - If the connection that declared the queue is closed, the queue is automatically deleted.
   - Exclusive queues cannot be shared between multiple consumers.
   - Even if another channel from the same connection tries to access it, it can.

2. Auto-Delete Queue
   - It is automatically deleted when the last consumer unsubscribes (disconnects) from it.
   - If no consumers are ever connected, the queue remains until RabbitMQ restarts or the queue is manually deleted.
