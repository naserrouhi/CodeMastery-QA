## Q2-14 What is an indexer?

- It allows an object to be accessed like an array.
- It doesn't have a name like a property but works similarly.
- It can have get and set accessors.
- It can take one or more parameters.

```csharp
public class Library
{
    private Dictionary<int, string> books = [];

    public string this[int id]
    {
        get => books.ContainsKey(id) ? books[id] : "Not Found";
        set => books[id] = value;
    }
}

var library = new Library();
library[1] = "C# in Depth";
Console.WriteLine(library[1]);
```
