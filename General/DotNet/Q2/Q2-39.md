# Q2-39: What is a packet?

- A packet is a small unit of data sent over a network.

- When large data (like a file or message) is transmitted, it is divided into smaller packets, sent separately, and then reassembled at the destination.

- Each packet in a TCP connection has its own sequence number, which is based on byte numbering, not packet numbering.

- Sequence numbers track each byte, not each packet.

- The first packet’s sequence number is the Initial Sequence Number (ISN).

- The sequence number for the next packet is the previous sequence number + number of bytes sent.
