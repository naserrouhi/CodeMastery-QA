# Q2-40: What's the difference between a flag and a data in TCP?

1. Flags (Control Bits)

    - Flags are special bits in the TCP header that control the connection.
    - Example: SYN, ACK, FIN, RST
    - A SYN packet used in a TCP handshake has only the SYN flag set but no data.

2. Data (Payload)

    - Data is the actual content being sent.
    - Data is in the TCP segment's payload, after the header.
