# Q2-110: What's the difference between SSO and RefreshToekn Authentication?

- SSO

    1. It allows a user to log in once and access multiple applications without needing to re-enter credentials.
    
    2. It works by using an Identity Provider (IdP) that issues authentication tokens, which different applications trust.
    
    3. For example, when you log into Google, you can access Gmail, Google Drive, and YouTube without logging in again.

- Refresh Token Authentication

    1. It is used within a single application to keep a user logged in without requiring them to re-enter credentials frequently.
    
    2. When a short-lived access token expires, the application uses a long-lived refresh token to request a new one.
    
    3. This is common in mobile apps or web APIs, where users stay authenticated without manual login every time.
