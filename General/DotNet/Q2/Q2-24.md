### **What if RabbitMQ Crashes Before Writing to Disk?**
RabbitMQ uses a **transaction log** to ensure data integrity. However, there is a small chance that a message might be lost if the crash happens before the message is written to disk. To minimize this risk:
- Use **publisher confirms** to ensure messages are safely stored.
- Use **clustering** to replicate data across multiple nodes.
