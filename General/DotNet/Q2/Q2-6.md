## Q2-6: What is Encapsulation?

Task:
- It bundles data (properties) and behavior (methods) within an object.
- It restricts access to certain components of an object, exposing only the necessary parts to external code.

Tools:
- Public methods (getters, setters, or other business logic) allow controlled access to private data.
- Access modifiers manage what can be accessed from outside the class.

Benefits:
- It allows internal implementation changes without affecting external code, enhancing flexibility.
- Reduces complexity for users interacting with the object since they don’t need to know its inner workings.
- It provides better data security and control over how data is accessed, leading to fewer unintended side effects and improved maintainability.
