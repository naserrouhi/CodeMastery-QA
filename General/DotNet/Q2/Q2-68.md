# Q2-68: What header and properties are for in RabbitMQ?

1. Properties

    - Built-in Metadata
    - Used for controling message behavior.
    - Types:
        - expiration: Defines how long a message stays in the queue.
        - delivery_mode: Ensures messages are saved to disk.
        - correlation_id: Useful in RPC
        - type: Helps consumers process messages differently based on their type.

```csharp
var properties = channel.CreateBasicProperties();
properties.Type = "email";  // This message is an email notification
```

2. Headers

    - Custom key-value pairs that allow more flexible metadata
    - Use cases:
        - Advanced routing in header exchanges (e.g., department, priority).
        - Adding extra context – Example: {"user": "admin", "priority": "high"} to tell consumers how to handle the message.
        - Filtering messages – Consumers can subscribe only to messages with specific headers.

```csharp
var properties = channel.CreateBasicProperties();
properties.Headers = new Dictionary<string, object>
{
    { "priority", "high" }
};
```
