# Q2-85: What's Kafka?

- Apache Kafka is a distributed event streaming.

- It acts as a publish-subscribe system where producers send events (messages) to topics, and consumers read those events asynchronously.

- Key Features:

    1. High Throughput & Scalability: Kafka can handle millions of messages per second and scale horizontally by adding more brokers.

    2. Fault Tolerance: Messages are replicated across multiple brokers to ensure data durability.

    3. Log-Based Storage: Kafka stores events in log segments, allowing consumers to replay messages.

    4. Real-Time Data Streaming: Supports event-driven architectures, stream processing, and analytics.

- How It Works:

    - Producers publish messages to topics.
    - Brokers store and distribute the messages.
    - Consumers subscribe to topics and process messages.
    - Partitions allow parallel processing by distributing data across multiple nodes.

- Common Use Cases:

    - Event Sourcing (logging user activity, audit trails).
    - Real-Time Analytics (tracking website traffic, financial transactions).
    - Data Pipelines (connecting microservices, log aggregation).
    - Message Queuing (though Kafka is more of an event store than a traditional queue).

- Examples:

    1. Producer

```csharp
class KafkaProducer
{
    public static async Task Main()
    {
        var config = new ProducerConfig { BootstrapServers = "localhost:9092" };

        using var producer = new ProducerBuilder<string, string>(config).Build();

        for (var i = 1; i <= 5; i++)
        {
            // Same key ensures messages go to the same partition
            var key = "User" + (i % 2);
            var value = $"Message {i}";

            var result = await producer.ProduceAsync("my-topic", new Message<string, string> { Key = key, Value = value });

            Console.WriteLine($"Produced: {value} to Partition {result.Partition}");
        }
    }
}
```

    2. Consumer

```csharp
class KafkaConsumer
{
    public static void Main()
    {
        var config = new ConsumerConfig
        {
            BootstrapServers = "localhost:9092",
            GroupId = "my-consumer-group",
            AutoOffsetReset = AutoOffsetReset.Earliest // Read from the beginning if no previous offset exists
        };

        using var consumer = new ConsumerBuilder<string, string>(config).Build();
        consumer.Subscribe("my-topic");

        Console.WriteLine("Consuming messages...");

        while (true)
        {
            try
            {
                var result = consumer.Consume(CancellationToken.None);
                Console.WriteLine($"Consumed: {result.Value} from Partition {result.Partition} with Key {result.Key}");
            }
            catch (OperationCanceledException)
            {
                break;
            }
        }

        consumer.Close();
    }
}
```

    3. Log Compaction

```csharp
class LogCompactionProducer
{
    public static async Task Main()
    {
        var config = new ProducerConfig { BootstrapServers = "localhost:9092" };

        using var producer = new ProducerBuilder<string, string>(config).Build();

        await producer.ProduceAsync("compacted-topic", new Message<string, string> { Key = "User1", Value = "Version 1" });
        await producer.ProduceAsync("compacted-topic", new Message<string, string> { Key = "User1", Value = "Version 2" }); // Overwrites "Version 1"

        Console.WriteLine("Messages sent to compacted topic.");
    }
}
```

    4. Kafka Partitions and Consumer Scaling

        - If multiple consumers exist in the same consumer group, Kafka distributes partitions.

```csharp
class PartitionAwareConsumer
{
    public static void Main()
    {
        var config = new ConsumerConfig
        {
            BootstrapServers = "localhost:9092",
            GroupId = "scalable-consumer-group",
            AutoOffsetReset = AutoOffsetReset.Earliest
        };

        using var consumer = new ConsumerBuilder<string, string>(config).Build();
        consumer.Subscribe("partitioned-topic");

        while (true)
        {
            try
            {
                var result = consumer.Consume(CancellationToken.None);
                Console.WriteLine($"Consumed from Partition {result.Partition}: {result.Value}");
            }
            catch (OperationCanceledException)
            {
                break;
            }
        }

        consumer.Close();
    }
}
```
