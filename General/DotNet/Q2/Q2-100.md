# Q2-100: What's Kernel?

- It is the core part of an operating system (OS) that manages hardware and system resources.

- It acts as a bridge between software applications and the computer's hardware.

- Key Functions

    1. Process Management – Controls running programs (multitasking, scheduling).

    2. Memory Management – Allocates RAM and ensures no program interferes with another.

    3. Device Management – Communicates with hardware (e.g., CPU, disk, network).

    4. File System Management – Handles file storage and retrieval.

    5. Security & Access Control – Manages permissions and system security.
