# Q2-58: What's Hashing?

- A hash is a function that takes an input and returns a string of characters, which is typically a sequence of numbers and letters.

- Use cases:

    1. Data Integrity: Hashing helps ensure that data hasn't been altered. If you hash some data and then later hash it again, the hash values should match if the data is the same.

    2. Password Storage: Instead of storing actual passwords, systems store the hash of a password. When a user logs in, the system hashes the entered password and compares it to the stored hash.

    3. Efficient Searching: Hashing is used in data structures like hash tables to quickly look up data.

- Properties of Hash Functions:

    1. Deterministic: The same input will always produce the same hash value.

    2. Fixed Size: The output hash is always of the same length, no matter the size of the input.

    3. Fast Computation: It should be quick to compute the hash for any given input.

    4. Pre-image Resistance: Given a hash value, it should be difficult to find the original input.

    5. Collision Resistance: It should be hard to find two different inputs that produce the same hash value.

- Common Hash Algorithms:

  - MD5: An older, faster hash function (but now considered insecure for cryptographic use).

  - SHA-1: More secure than MD5 but also considered weak in modern security practices.

  - SHA-256: Part of the SHA-2 family, considered secure and widely used.

- Example:

  - When downloading a file, the website might provide the file's hash. After downloading, you can hash the file on your device and compare it to the provided hash to ensure it wasn’t tampered with during download.

- the SHA-256 hash algorithm always produces a 256-bit hash value.
