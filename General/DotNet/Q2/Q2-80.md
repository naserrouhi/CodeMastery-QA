# Q2-80: What's Log-based system?

- Log-based systems record changes as a sequence of ordered logs (append-only records) instead of directly modifying the database or system state.

- These logs serve as the source of truth and ensure consistency, fault tolerance, and recovery.

- Queues That Use Log-Based Systems:

    1. Quorum Queues → Use a log-based system with Raft for consistency.

    2. Stream Queues → Use log storage to persist messages in an ordered, append-only structure.

    3. Classic Durable Queues → Use a disk-based log (but not Raft) for persistence, where messages are written to disk before acknowledgment.
