# Q2-61: What's the difference between hashing and encryption?

1. Hashing:

    - It produces a unique fixed-size output.
    - One-way process: You cannot reverse or recover the original data.

2. Encryption:

    - The output size depends on the size of the input data.
    - Two-way process: The data can be decrypted back into its original.

- Use cases:

  - Hashing:

    - Data Integrity: Verifying if data has been modified.
    - Password Storage
    - Digital Signatures: Ensuring a message hasn't been altered.

  - Encryption:

    - Protecting sensitive data during transmission like emails.
    - Secure Communication like HTTPS to ensure privacy during online communication.
