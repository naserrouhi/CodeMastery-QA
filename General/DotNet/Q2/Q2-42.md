# Q2-42: What's Port?

Other connections like tcp? What is protocol?

- It is a logical connection point used by network protocols to direct traffic to the correct application or service running on a computer.

- It helps identify specific applications or services on a machine and ensures that data is delivered to the correct place.

- Ports are primarily used by transport layer protocols like TCP to establish communication between applications on different devices.

- A port number allows the operating system to know which application or service should handle a particular incoming or outgoing message.

- Port numbers are 16-bit numbers, so they range from 0 to 65535.

  - Well-Known Ports (0-1023): Reserved for common services like HTTP (80), FTP (21), and SSH (22).

  - Registered Ports (1024-49151): These ports are assigned to specific applications but can be used by other programs. like Microsoft SQL Server (1433), MySQL (3306)

  - Dynamic/Private Ports (49152-65535): Assigned dynamically by the OS for temporary or client-side communication.

- Analogy:

  - Think of a port as a door in a building:
  - The building is the computer (device).
  - The door is the port that allows traffic to enter or leave.
  - Each door can be assigned to a specific department or service (application).
  - When data arrives, it knows which door to go through to reach the correct destination.

- One application can listen on a specific port.

- If an application is running multiple instances, they may each use different port numbers.

- Different applications can also use the same port number if they are bound to different IP addresses or different protocols.
