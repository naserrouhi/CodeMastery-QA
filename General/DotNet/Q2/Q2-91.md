# Q2-91: What's bootstrap server?

- It is a broker (or a list of brokers) that a client (producer or consumer) first connects to.

- It helps the client discover the entire Kafka cluster, and get the initial metadata about the cluster (like available brokers and topics).

- The word bootstrap means "initialize".

- When a client (producer/consumer) connects, it only needs the address of one or a few brokers (bootstrap servers).

- The bootstrap server then gives the client a full list of brokers in the cluster.

- The client can now communicate with the right broker for sending or receiving messages.

```csharp
var config = new ProducerConfig
{
    BootstrapServers = "broker1:9092,broker2:9092,broker3:9092"
};

using var producer = new ProducerBuilder<Null, string>(config).Build();
await producer.ProduceAsync("test-topic", new Message<Null, string> { Value = "Hello Kafka!" });
```

- Here, "broker1:9092,broker2:9092,broker3:9092" are bootstrap servers that help the producer find the correct Kafka broker to send the message.
