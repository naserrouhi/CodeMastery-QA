# Q2-35: How exchange types map to common communication types in RabbitMQ?

didnt understnad.

1. RPC

    - Exchange Type: direct or topic (depending on the routing needs)

2. Event-Driven Messaging

    - Exchange Type: fanout

3. Work Queue (Task Queue)

    - Exchange Type: direct

4. Direct Messaging

    - Exchange Type: direct

5. Topic-Based Messaging

    - Exchange Type: topic

6. Fanout Messaging

    - Exchange Type: fanout

7. Dead Letter Queue (DLQ)

    - Exchange Type: direct (typically) or topic (for more advanced routing)
