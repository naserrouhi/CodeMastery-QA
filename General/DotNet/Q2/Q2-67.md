# Q2-67: What's the difference between Message-Driven Programming and Message-Oriented Middleware?

1. Message-Driven Programming

    - A programming style that its focus is on loose coupling, meaning components are independent and do not need to know each other directly.

2. Message-Oriented Middleware (MOM)

    - A technology (tool) that helps applications send and receive messages in a distributed system.

    - It acts as a bridge between different systems, handling message routing, queuing, delivery, and reliability.

    - Examples: RabbitMQ, Apache Kafka, ActiveMQ, IBM MQ

- Message-driven programming is a design approach, while message-oriented middleware is the tool that enables it.
