# Q2-102: What are Serverless Functions?

- Serverless functions in Azure refer to small, event-driven pieces of code that run in a fully managed environment without the need to manage servers.

- In Azure, this is implemented using Azure Functions.

- Key Features:

  - Event-driven: Triggered by various events (e.g., HTTP requests, timers, queue messages, blob storage changes).
  - Auto-scaling: Scales automatically based on demand.
  - Pay-per-use: You are charged only for the execution time.
  - Managed environment: Microsoft handles infrastructure, scaling, and maintenance.

- Example:

  - A function that runs when a new file is uploaded to Azure Blob Storage and processes the file.

```csharp
public static class MyFunction
{
    [FunctionName("HelloFunction")]
    public static IActionResult Run([HttpTrigger(AuthorizationLevel.Function, "get", "post")] HttpRequest req, ILogger log)
    {
        log.LogInformation("C# HTTP trigger function processed a request.");
        var name = req.Query["name"];

        return new OkObjectResult($"Hello, {name}!");
    }
}
```

- Azure Functions is a serverless compute service in Azure that lets you run small pieces of code (functions) in response to events without managing infrastructure.
