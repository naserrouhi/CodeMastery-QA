# Q2-43: What is the Flow Control?

- It is a mechanism in network protocols (such as TCP) that regulates the rate of data transmission between two devices to ensure that the sender does not overwhelm the receiver with more data than it can handle.

- The receiver informs the sender about its available buffer space by sending a window size in each acknowledgment (ACK).

- Window Size:

    - It defines how much data (in bytes) the receiver is willing to accept.
    - It change during the connection, based on the receiver's buffer capacity.
    - This is part of the flow control mechanism in TCP.

- Buffer Capacity:

    - It refers to the amount of data that a receiver can temporarily store in memory (buffer) while waiting for further processing or acknowledgment.
