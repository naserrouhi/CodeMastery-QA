- A JWT (JSON Web Token) is a compact, self-contained token used for authentication and secure data exchange between parties.

- It consists of three parts separated by dots (.):

    1. Header:

      - This specifies the algorithm used for signing and declares it as a JWT.
      - It base64 encodes and then be used in the token.

```json
{
  "alg": "HS256",
  "typ": "JWT"
}
```

    2. Payload:
    
        - Contains claims (user data, expiration time, roles, etc.).
        - It base64 encodes and then be used in the token.
        - sub: User Id
        - iat: Issued At (Timestamp)

```json
{
  "sub": "1234567890",
  "name": "John Doe",
  "iat": 1711893722,
  "exp": 1711900922
}
```

    3. Signature:
    
      - Ensures the token is not tampered with using a secret key.
      - It is generated using the header, payload, and a secret key.

```csharp
HMACSHA256(
  base64UrlEncode(header) + "." +
  base64UrlEncode(payload),
  mySecretKey
)
```

- Secret Key

    - It is used to sign the JWT and verify its authenticity.
    - Only the server should know this key.
