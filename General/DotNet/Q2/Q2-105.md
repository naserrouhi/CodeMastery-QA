# Q2-105: What are LDAP and Kerberos?

ticket?secure authentication? Directory services? send password over internet?

- They are two protocols commonly used in AD for authentication and directory access.

1. LDAP (Lightweight Directory Access Protocol)

    - A protocol used to query and modify directory services (like Active Directory).
    - Helps retrieve user details, groups, and permissions from AD.
    - Works over TCP/IP (port 389 for unencrypted, 636 for encrypted/LDAPS).
    - Used for authentication and user lookup but does not handle secure authentication by itself.
    - Example: A web application queries AD to check if a username exists.

2. Kerberos

    - A secure authentication protocol that provides single sign-on (SSO).
    - Uses tickets to verify identities without sending passwords over the network.
    - Works on port 88 and requires a Key Distribution Center (KDC) (which AD provides).
    - More secure than LDAP alone because passwords are never sent over the network.
    - Example: A user logs into a corporate laptop and gets a Kerberos ticket, which allows access to shared folders and apps without needing to log in again.
