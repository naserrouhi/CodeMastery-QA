# Q2-50: What is DHCP?

- DHCP (Dynamic Host Configuration Protocol) is a network protocol that automatically assigns IP addresses to devices on a network.

- It ensures that each device gets a unique IP address without manual configuration.

- Steps:

    1. Device connects to the network (e.g., laptop joins Wi-Fi).

    2. Device sends a request to the DHCP server asking for an IP address.

    3. DHCP server assigns an IP address from its available pool and also provides other settings like:
        - Subnet mask
        - Default gateway
        - DNS servers

    4. Device uses the assigned IP until it expires (lease time). After that, it renews or gets a new one.
