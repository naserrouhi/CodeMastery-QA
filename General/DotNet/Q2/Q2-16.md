# Q2-16: What is an Event?

- Defenition:

  - It is a mechanism that allows objects to communicate in a loosely coupled way.

  - It is based on the observer pattern.

  - It can only be raised inside the class where it's declared.

  - It is a wrapper around a delegate that allows a class to notify subscribers (multiple listeners) when a specific action occurs.

    - Publisher (Event Source): The class that defines and raises an event.
    - Subscriber (Event Listener): The class that handles the event.

- Steps:

    1. Events must be based on delegates. (The delegate defines the event signature.)

```csharp
public delegate void MyEventHandler(string message);

public class Publisher
{
    public event MyEventHandler OnMessageSent; //Declaring

    public void SendMessage(string message)
    {
        Console.WriteLine($"Publisher: Sending message: {message}");
        OnMessageSent?.Invoke(message); //Raising
    }
}
```

    2. Subscribers register methods (event handlers) to an event.

```csharp
public class Subscriber
{
    public void HandleMessage(string message)
    {
        Console.WriteLine($"Subscriber received: {message}");
    }
}

var publisher = new Publisher();
var subscriber = new Subscriber();

publisher.OnMessageSent += subscriber.HandleMessage; //Subscribing
```

    3. The event invokes all registered handlers when triggered.

```csharp
publisher.SendMessage("Hello, Events!"); // Triggering

//Publisher: Sending message: Hello, Events!
//Subscriber received: Hello, Events!
```

- Unsubscribing from an Event

```csharp
publisher.OnMessageSent -= subscriber.HandleMessage;
```

- Events with Built-in Delegates

Instead of custom delegates, we can use EventHandler<T>.

    - Using EventHandler

```csharp
public class Publisher
{
    public event EventHandler OnMessageSent;

    public void SendMessage()
    {
        Console.WriteLine("Publisher: Sending message...");
        OnMessageSent?.Invoke(this, EventArgs.Empty); // Raising event
    }
}
```

    - Using EventHandler<T>

```csharp
public class MessageEventArgs : EventArgs
{
    public string Message { get; }
    public MessageEventArgs(string message) => Message = message;
}

public class Publisher
{
    public event EventHandler<MessageEventArgs> OnMessageSent;

    public void SendMessage(string message)
    {
        Console.WriteLine($"Publisher: Sending message: {message}");
        OnMessageSent?.Invoke(this, new MessageEventArgs(message));
    }
}

public class Subscriber
{
    public void HandleMessage(object sender, MessageEventArgs e)
    {
        Console.WriteLine($"Subscriber received: {e.Message}");
    }
}
```
