# Q2-60: What is Encryption?

- It is the process of converting plain, readable data (called plaintext) into an unreadable format (called ciphertext) to protect it from unauthorized access.

- This process is done using a specific algorithm and an encryption key.

- Encryption Algorithm:

  - The method used to transform the plaintext into ciphertext.
  - For example, AES

- Encryption Key:

  - A secret key used to perform the encryption.

- Types:

    1. Symmetric Encryption:

        - The same key is used for both encrypting and decrypting the data.
        - Example: AES (Advanced Encryption Standard)

    2. Asymmetric Encryption:

       - A public key for encrypting and a private key for decrypting.
       - Example: RSA (Rivest-Shamir-Adleman)

- Why is the Asymmetric More Secure than the Symmetric?

  - In symmetric encryption, the secret key must be shared between parties, and this creates a risk. If someone intercepts the secret key during transmission, they can easily decrypt the data.

  - In asymmetric encryption, the private key is never shared. The public key is freely distributed, and only the intended recipient, who holds the private key, can decrypt the data. Since the private key is not transmitted, it cannot be intercepted by third parties.

- The length of the encrypted message will typically be larger than the original data.
