# Q2-104: What is Active Directory?

LDAP, Kerberos
SSO
SAML
OAuth

- Active Directory (AD) is a directory service developed by Microsoft for managing users, devices, and resources in a network.

- Key Features:

  - User & Group Management
  - Authentication & Authorization – Uses LDAP and Kerberos to verify users.
  - Centralized Management
  - Domain Controller (DC) – A server that runs AD and handles authentication requests.

- Azure Active Directory (Azure AD)

  - Cloud-based identity and access management service.
  - Used for SSO (Single Sign-On) in cloud apps like Microsoft 365.
  - Supports Multi-Factor Authentication (MFA) and role-based access control (RBAC).
  - Uses OAuth, SAML, OpenID Connect

- Azure AD B2B:

  - If your customers are companies with Azure AD accounts, you can enable that to allow them to sign in.

- Azure AD B2C:

  - It is designed for public users.
  - Supports Google, Facebook, Microsoft, and custom email/password logins.

- Differences of AD and Azure AD
  
  - AD -->       On-premises, LADP/Kerberos,            B2B,     Username/Password
  - Azure AD --> Cloud-based, OAuth 2.0/OpenID Connect, B2B/B2C, Access Token
