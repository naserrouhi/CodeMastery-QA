- It is an approach to building and running applications that fully leverage the cloud environment.

- It focuses on scalability, flexibility, and automation.

- Cloud-native applications are designed to be resilient, scalable, and dynamically managed using modern cloud technologies.

- Key Features:

    1. Microservices Architecture: Applications are built as a collection of small, loosely coupled services.

    2. Containerization: Services run in lightweight containers (e.g., Docker) for portability.

    3. Orchestration: Tools like Kubernetes manage deployment, scaling, and networking.

    4. API-Driven: Services communicate through APIs, enabling flexibility and integration.

    5. DevOps & Automation: Continuous Integration/Continuous Deployment (CI/CD) automates software delivery.

    6. Scalability & Resilience: Apps scale dynamically and recover quickly from failures.

    7. Cloud-Managed Services: Use of cloud platforms (AWS, Azure, GCP) for databases, messaging, monitoring, etc.

- Example of Cloud-Native Technologies:

    - Containerization: Docker, Podman
    - Orchestration: Kubernetes, OpenShift
    - Serverless: AWS Lambda, Azure Functions
    - Messaging: Kafka, RabbitMQ (Cloud-hosted)
    - CI/CD: Jenkins, GitHub Actions, GitLab CI/CD
    - Monitoring: Prometheus, Grafana

- Benefits:

    - Faster development & deployment (agile workflows)
    - Better resource utilization (efficient scaling)
    - Improved fault tolerance (self-healing systems)
    - Cost optimization (pay for what you use)
