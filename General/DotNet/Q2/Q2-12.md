## Q2-12: What's the difference between an interface and an abstract class?

- Definition

    - Abstract Class:

        - It is designed to be a base class for other classes.
        - It allows to define a common structure and behavior for derived classes.

    - Interface:
    
        - It is a contract that defines a set of members that an object must implement.
        - It specifies what a type should do but not how it should do it.

- Usage

    - Abstract Class:  

        - Providing a common base implementation for derived classes. (Override)
        - Sharing code or behavior among related classes. (Reuse)
        - Enforcing a hierarchy or a specific structure in your classes. (Structure)

    - Interface:

        - Defining a contract that multiple unrelated classes can implement. (Contract)
        - Achieve polymorphism across unrelated types.
        - It promotes loose coupling.
