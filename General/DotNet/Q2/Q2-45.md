# Q2-45: What's an IP Address?

- It is a unique identifier assigned to each device on a network, similar to a home address.

- It helps devices find and communicate with each other.

- Types of IP addresses:

    1. IPv4:

        - 32-bit address
        - Example: 192.168.1.1
        - Dotted Decimal Notation with 4 octets (0 to 255) (8 bits per octet)


    2. IPv6:
        
        - 128-bit address
        - Example: 2001:0db8:85a3:0000:0000:8a2e:0370:7334
        - Hexadecimal Notation with 8 groups of 4 hexadecimal digits (16 bits per group), separated by colons (:).
