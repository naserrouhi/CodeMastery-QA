# Q2-73: What's the difference between Nack and Reject in RabbitMQ?

- BasicNack supports batch rejections (multiple=true), but BasicReject can only reject one message at a time.

- Both methods allow requeueing or discarding messages.

```csharp
channel.BasicReject(deliveryTag, requeue: true);
```

- When multiple=true, RabbitMQ nacks all messages that were sent before (or exactly at) the given deliveryTag and have not been acknowledged yet (delivery tags ≤ deliveryTag).

- Use cases of multiple parameter:

  - Batch processing: When many messages are processed at once.
  - If consumer crashes: To nack all unprocessed messages together.
