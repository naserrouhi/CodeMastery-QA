# Q2-69: What's the difference between Nack and not Acknowledging in RabbitMQ?

1. Nack

    - The consumer can decide whether to requeue the message or discard it.

```csharp
consumer.Received += (model, ea) =>
{
    try
    {
        var message = Encoding.UTF8.GetString(ea.Body.ToArray());
        ProcessMessage(message);

        channel.BasicAck(deliveryTag: ea.DeliveryTag, //Unique Id of the message
                         multiple: false //false = only this message, true = all previous unacked messages
        );
    }
    catch (Exception)
    {
        channel.BasicNack(deliveryTag: ea.DeliveryTag,
                          multiple: false,
                          requeue: true //true = send back to queue, false = discard message
        );
    }
};
```

2. Not Acknowledging

    - If the consumer crashes or disconnects, RabbitMQ will redeliver the message to another consumer.
