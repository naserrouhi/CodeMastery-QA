# Q2-79: What's the Raft algorithm?

- It is a consensus algorithm used in distributed systems to ensure that multiple nodes agree on a single, consistent state, even if some nodes fail or the network is unreliable.

- Raft has three main roles in a cluster:

    1. Leader: Handles all writes and ensures data consistency.
    2. Followers: Accept and replicate data from the leader.
    3. Candidates: Try to become the leader if the leader fails.

- Raft Process:

    1. Leader Election:

        - If the leader fails or a network partition happens, followers start an election.

        - One follower becomes a candidate, requests votes, and if it gets a majority, it becomes the new leader.

    2. Log Replication:

        - The leader receives all writes and replicates them to followers.
        - Followers confirm they received the data (acknowledgment).

    3. Commit and Apply:

        - Once a majority of followers acknowledge a log entry, the leader marks it as committed.
        - The leader and followers then apply the change to their state.

- A consensus algorithm is a method used in distributed systems to ensure that multiple nodes (servers) agree on a single, consistent state even if some nodes fail or messages get delayed.
