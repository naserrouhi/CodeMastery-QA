# Q2-101: What are Iaas, Paas, Saas?

- They are different cloud service models that describe how cloud resources and services are delivered to users.

1. IaaS (Infrastructure as a Service)

    - Provides virtualized computing resources over the internet, such as virtual machines, storage, and networking.

    - Example: AWS, Azure, GCP.

    - You manage: Operating systems, applications, and data.
    - Cloud provider manages: Servers, storage, networking, and virtualization.

    - Example use case: You need to host a virtual server and have complete control over the operating system and software stack but don’t want to manage physical hardware.

2. PaaS (Platform as a Service)

    - Provides a platform that allows developers to build, deploy, and manage applications without worrying about the underlying infrastructure.

    - Example: Heroku, Google App Engine, Microsoft Azure App Services.

    - You manage: Applications and data.
    - Cloud provider manages: Servers, storage, networking, operating systems, and platform.

    - Example use case: You want to develop an app but don’t want to handle the infrastructure or platform setup, just focus on writing and deploying your code.

3. SaaS (Software as a Service)

    - Delivers software applications over the internet. These applications are hosted and managed by the provider, and users access them through a browser or client.

    - Example: Google Workspace (Gmail, Docs), Microsoft 365, Dropbox.

    - You manage: Your usage of the software.
    - Cloud provider manages: The application, servers, storage, and everything related to the software's operation.

    - Example use case: You use Gmail or Dropbox for email and file storage without worrying about infrastructure or software maintenance.
