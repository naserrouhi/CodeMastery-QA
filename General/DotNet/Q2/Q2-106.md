# Q2-106: What are Directory Services?

- They are systems that store, manage, and organize information about users, computers, networks, and other resources in a structured way.

- Common Uses:

    1. Authentication
    2. Authorization
    3. Resource Management
    4. Centralized Administration: Manages users and policies from one place.

- Popular Directory Services:

    - AD: Microsoft’s solution for managing Windows networks.
    - LDAP: A protocol used to access directory services.
    - OpenLDAP: An open-source directory service based on LDAP.
    - Azure AD: A cloud-based identity management service from Microsoft.

- Resource Management:

    - In directory services, it means keeping track of and organizing network resources like computers, printers, shared folders, and users.

    1. Storing information: Directory service keeps details about each resource (e.g., computer names, IP addresses, user accounts).

    2. Keeping records of changes – If a user or device joins, leaves, or changes roles, the directory updates automatically.

    3. Making resources searchable – Users can quickly find and access network resources (e.g., a shared printer or a file server).

    - Example:

        - In a company, Active Directory keeps a list of employees and their computers.

        - If an employee moves to another department, their permissions update automatically based on their new role.

        - If a printer is removed from the network, it disappears from the directory so users don’t see outdated resources.
