# Q2-19: What does SelectMany do?

- It is used when working with collections inside collections (nested collections).

- It flattens multiple sub-collections into a single collection.

    1. Falttening (One parameter)

```csharp
var students = new List<Student>
{
    new Student { Name = "Alice", Subjects = new List<string> { "Math", "Science" } },
    new Student { Name = "Bob", Subjects = new List<string> { "English", "History" } }
};

var subjects = students.SelectMany(s => s.Subjects);  
// Result: Flattened List → { "Math", "Science", "English", "History" }
```

    2. Flattening + Transformation (Two parameters) 

```csharp
var studentSubjects = students.SelectMany(
    s => s.Subjects,   // First parameter: Extracts the list of subjects
    (s, subject) => $"{s.Name} - {subject}"  // Second parameter: Transforms data
);
```

- Select only takes one parameter, which is the transformation function. Unlike SelectMany(), it does not flatten collections.
