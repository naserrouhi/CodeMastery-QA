# Q2-17: What are LINQ methods?

- LINQ (Language Integrated Query) methods are a set of extension methods.

- They work on IEnumerable<T> or IQueryable<T> collections.

- It follows functional programming principles because:

    1. Immutability: It does not modify the original collection but creates a new result.

    2. Higher-Order Functions: It uses functions (lambdas) as arguments.

    3. Declarative Syntax: Instead of using loops, LINQ expresses "what" to do, not "how" to do it.

    4. Composability: Methods can be combined (e.g., .Where().Select().OrderBy()).

    5. Lazy Evaluation: Queries are executed only when needed, improving performance.
