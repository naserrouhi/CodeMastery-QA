# Q2-55: What's NAT?

- NAT (Network Address Translation) is a method used by routers to allow multiple devices on a local network to share a single public IP address when accessing the internet.

- Importance:

    1. IPv4 addresses are limited
    2. Security: Hides private IP addresses from the internet,

- Example:

    - Your Wi-Fi router has a public IP address (203.0.113.1).

    - Your devices have private IP addresses (192.168.1.2, 192.168.1.3).

    - When your laptop requests a website, the router uses NAT to send that request as if it came from 203.0.113.1, and when the website responds, it sends the data to the right device using the private IP.
