## Q2-11: What is an Abstract Class?

It is a class that is designed to be a base class for other classes. It can contain both abstract (unimplemented) and concrete (implemented) members, allowing it to define a common structure and behavior for derived classes.


- Abstract Class Characteristics
     
    - General Rules
        - Cannot be instantiated.
        - Can have instance members, and constructors. 
        - Can have abstract members that must be implemented by derived classes.
        - Can have concrete members with default implementations.
        - A class can inherit from only one abstract class.
        - Members can have access modifiers.
        - Cannot be static.

    - Abstract Members
        - Use the `abstract` keyword to define abstract members.
        - Derived classes must implement all abstract members unless they are also abstract.

    - Virtual Members
        - Can have virtual members that provide a default implementation but can be overridden in derived classes.
        - Use the `virtual` keyword to define virtual members.**
        - Derived classes can override virtual members using the `override` keyword.

    - Static Members
        - Can have static fields, properties, and methods.
        - Cannot have static abstract memebr.

    - Constructors
        - Constructors are called when an instance of a derived class is created.


```csharp
public abstract class Animal
{
    // Instance field
    private string _name;

    // Constructor
    public Animal(string name)
    {
        _name = name;
    }

    // Abstract method (must be implemented by derived classes)
    public abstract void MakeSound();

    // Virtual method (can be overridden by derived classes)
    public virtual void DisplayInfo()
    {
        Console.WriteLine($"Name: {_name}");
    }

    // Static field
    public static int TotalAnimals = 0;

    // Static method
    public static void IncrementAnimalCount()
    {
        TotalAnimals++;
        Console.WriteLine($"Total Animals: {TotalAnimals}");
    }
}

// Derived Class
public class Dog : Animal
{
    // Constructor
    public Dog(string name) : base(name) { }

    // Implement abstract method
    public override void MakeSound()
    {
        Console.WriteLine("Woof!");
    }

    // Override virtual method
    public override void DisplayInfo()
    {
        base.DisplayInfo();
        Console.WriteLine("Type: Dog");
    }
}
```
