## Q2-9: What's the difference between Encapsulation and Abstraction?

- Encapsulation is about protecting data and controlling access to it.

- Abstraction is about simplifying complexity by focusing on what an object does rather than how it does it.

- Encapsulation is like a pill capsule. The capsule hides the medicine inside (implementation) and only exposes the outer shell (interface). You don't need to know what's inside to use it.

- Abstraction is like a car's steering wheel. You only need to know how to turn the wheel to drive the car (what it does). You don't need to know how the engine or transmission works (how it does it).

- Encapsulation: "You can only access components in the way I allow."

- Abstraction: "Just use my features; you don't need to know how they work."
