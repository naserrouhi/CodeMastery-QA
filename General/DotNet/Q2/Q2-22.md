# Q2-22: Explain key concepts of functional programming

1. Higher-Order Functions (HOF)

    - It is a function that takes one or more functions as arguments or returns a function as a result.

```csharp
static int ApplyOperation(int a, int b, Func<int, int, int> operation)
{
    return operation(a, b);
}

var sum = ApplyOperation(5, 3, (a, b) => a + b);
```

2. Immutability

    - It means that data cannot be changed after it is created.
    - C# supports immutability through readonly fields, immutable collections, and readonly structs.

```csharp
public class Person
{
    public string Name { get; }
    public int Age { get; }

    public Person(string name, int age)
    {
        Name = name;
        Age = age;
    }

    public Person WithName(string newName) => new Person(newName, Age);
}
```

3. Pure Functions

    - It is a function that always produces the same output for the same input and does not have any side effects (e.g., changing external state).

```csharp
static int Add(int a, int b)
{
    return a + b;
}
```

4. Callbacks

- It is a function that is passed as an argument to another function and is executed when a certain event or condition occurs.

```csharp
static void ProcessData(int data, Action<int> callback)
{
    var processedData = data * 2;
    callback(processedData);
}

ProcessData(5, result => Console.WriteLine($"Processed data: {result}"));
```

5. Promises

    - C# doesn't have a native concept of Promises, but it has Task and async/await for handling asynchronous operations, which serve a similar purpose.

```csharp
static async Task<int> GetDataAsync()
{
    await Task.Delay(1000); // Simulate some async operation
    return 42;
}

static async Task Main()
{
    var result = await GetDataAsync();  // Waiting for the "promise" to resolve
    Console.WriteLine($"Received data: {result}");
}
```

6. Function Composition

    - It allows combining functions to build more complex ones.

```csharp
static Func<int, int> Add2 = x => x + 2;
static Func<int, int> MultiplyBy3 = x => x * 3;

static void Main()
{
    var composedFunction = Compose(Add2, MultiplyBy3);
    Console.WriteLine(composedFunction(4));
}

static Func<int, int> Compose(Func<int, int> f1, Func<int, int> f2)
{
    return x => f2(f1(x));
}
```

7. Lazy Evaluation

    - It is a technique where expressions are not evaluated until their values are actually needed.
    - IEnumerable and LINQ often implement lazy evaluation.
    - Be careful of multiple evaluaions.

```csharp
var numbers = Enumerable.Range(1, 10).Where(x => x % 2 == 0);

foreach (var num in numbers) // Lazy evaluation happens here
    Console.WriteLine(num);

foreach (var num in numbers) // Lazy evaluation happens again
    Console.WriteLine(num);
```
