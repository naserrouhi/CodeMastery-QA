# Q2-54: What is the Firewall?

- It is a security system that monitors and controls network traffic.

- It acts as a barrier between a trusted network (like your home or office) and an untrusted network (like the internet).

- Types:

    1. Network Firewall – Protects an entire network (installed on routers or servers).

    2. Host-Based Firewall – Protects a single device (installed on PCs, like Windows Defender Firewall).

    3. Hardware Firewall – A physical device used for large networks.

    4. Software Firewall – A program running on a computer or server.
