# Q2-108: What's the difference between Token-Based and Session-Based Authentication?

JWT?

1. Session-Based Authentication

    - The server stores user information after login.
    - The user gets a session Id stored in a cookie.
    - Every request sends the session Id, and the server checks it.
    - When the user logs out the server removes the session data.

2. Token-Based Authentication

    - The server does not store user data; instead, it gives a token after login.
    - The token is self-contained (it has all needed info, like user Id and permissions).
    - The user sends the token in each request (usually in the headers).
    - The server validates the token but does not store it.
    - Sessions require server memory, but tokens don’t (better for scalability).
