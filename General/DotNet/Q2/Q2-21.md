# Q2-21: Which syntaxes does LINQ have?

- It has Query syntax and Method (Fluent) syntax.

- Method syntax is more common. Becasue some query syntax doesn't support some of operations. (eg. sum, distinct)

- Join with query syntax:

```csharp
var innerJoin = from e in employees
                join d in departments
                on e.DepartmentId equals d.Id
                select new
                {
                    EmployeeName = e.Name,
                    DepartmentName = d.Name
                };
```

- Left Join

    1. Query Syntax

```csharp
var leftJoin = from e in employees
               join d in departments on e.DepartmentId equals d.Id into deptGroup
               from d in deptGroup.DefaultIfEmpty()
               select new 
               {
                   EmployeeName = e.Name,
                   DepartmentName = d?.Name ?? "No Department"
               };
```

    2. Method Syntax

```csharp
var leftJoin = employees.GroupJoin(departments, 
                                   e => e.DepartmentId, 
                                   d => d.Id, 
                                   (e, deptGroup) => new { e, deptGroup })
                        .SelectMany(temp => temp.deptGroup.DefaultIfEmpty(),
                                    (temp, d) => new
                                    {
                                        EmployeeName = temp.e.Name,
                                        DepartmentName = d?.Name ?? "No Department"
                                    });
```
