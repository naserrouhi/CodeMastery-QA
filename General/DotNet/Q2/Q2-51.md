# Q2-51: What is a subnet mask?

- It is a number that determines which part of an IP address belongs to the network and which part identifies a specific device (host) in that network.

- Importance:

    1. Defines network boundaries: Helps devices know if another IP address is in the same network or a different one.

    2. Prevents unnecessary traffic: If an IP is in the same network, data is sent directly; otherwise, it is sent to a router.

    3. Allows subnetting – Networks can be divided into smaller subnetworks for better organization and security.

- Example:

    - IP Address: 192.168.1.10
    - Subnet Mask: 255.255.255.0
    - The 255.255.255 part shows the network portion (192.168.1).
    - The .0 tells that the remaining part (.10) is the host portion.
