# Q2-52: What is a default gateway?

- Router is the actual device that manages network traffic.

- Default Gateway is the IP address used by devices to send data outside their network (usually the router's IP).

- When your device needs to send data outside the network (e.g., visiting google.com), it doesn't know where to send it.

- The default gateway receives the data and forwards it to the internet or another network.

- Importance:

  - Enables internet access by forwarding traffic outside your network.
  - Routes data correctly between different networks.
