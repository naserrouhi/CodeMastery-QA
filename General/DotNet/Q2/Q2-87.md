# Q2-87: Why Kafka is Not Based on AMQP?

1. Log-Based Storage vs. Message Queueing:

    - Kafka stores messages in a persistent log and allows consumers to replay messages from any point.

    - AMQP queues deliver messages once per consumer and remove them after acknowledgment.

2. Pull-Based Consumption vs. Push-Based:

    - Kafka pulls messages when the consumer is ready.

    - AMQP (RabbitMQ) pushes messages to consumers.

3. Designed for Scalability & High Throughput:

    - Kafka scales better for big data and real-time analytics, while AMQP is more about reliable message delivery in enterprise applications.

4. Decentralized Consumer State:

    - Kafka does not track consumer state; consumers decide which offset to read from.

    - AMQP brokers track which messages were delivered and acknowledged.
