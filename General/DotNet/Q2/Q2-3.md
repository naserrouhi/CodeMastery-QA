## Q2-3: What is OOD?

- Object-Oriented Design is a design approach that helps structure software using OOP principles.

- It helps developers create scalable, maintainable, and efficient software architecture.

- First, we design (OOD), then we code (OOP).

- It contains:

    - Identifying classes, objects, and their relationships
    - Defining how objects interact
    - Using design patterns
