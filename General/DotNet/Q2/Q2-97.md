# Q2-97: What's Azure?


Active Directory

- It is Microsoft’s cloud computing platform that provides services like computing, storage, networking, databases, and AI.

- It helps businesses run applications, store data, and build solutions without managing physical hardware.

- Key Features:

    1. Infrastructure as a Service (IaaS) → Virtual Machines, Networking, Storage.
    2. Platform as a Service (PaaS) → Web Apps, Databases, Serverless Functions.
    3. Software as a Service (SaaS) → Office 365, Azure DevOps.
    4. AI & Machine Learning → Azure AI, Cognitive Services.
    5. Containers & Kubernetes → Azure Kubernetes Service (AKS), Azure Container Apps.
    6. Security & Identity → Azure Active Directory (Azure AD).

- Common Services:

  - Compute → Virtual Machines (VMs), Azure Functions (Serverless).
  - Storage → Blob Storage, SQL Database, Cosmos DB.
  - Networking → Virtual Network (VNet), Load Balancer.
  - Monitoring → Azure Monitor, Application Insights.
