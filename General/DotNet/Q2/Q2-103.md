# Q2-103: What are Cognitive services?

- Azure Cognitive Services is a collection of AI-powered APIs and services that allow developers to add vision, speech, language, and decision-making capabilities to applications without needing deep AI expertise.

- Main Categories:

  - Vision: Image recognition, OCR, facial recognition (e.g., Computer Vision, Face API).
  - Speech: Speech-to-text, text-to-speech, speech translation (e.g., Speech API).
  - Language: Natural language processing (e.g., Text Analytics, Translator).
  - Decision: Personalized recommendations (e.g., Personalizer).
  - Search: AI-powered search capabilities (e.g., Bing Search API).

```csharp
class Program
{
    private static readonly string subscriptionKey = "YOUR_COGNITIVE_SERVICE_KEY";
    private static readonly string endpoint = "YOUR_COGNITIVE_SERVICE_ENDPOINT";
    
    static async Task Main(string[] args)
    {
        var imageUrl = "https://example.com/image.jpg";
        await AnalyzeImage(imageUrl);
    }

    static async Task AnalyzeImage(string imageUrl)
    {
        var requestUrl = $"{endpoint}/vision/v3.2/analyze?visualFeatures=Description";

        using HttpClient client = new HttpClient();
        client.DefaultRequestHeaders.Add("Ocp-Apim-Subscription-Key", subscriptionKey);

        var jsonContent = JsonSerializer.Serialize(new { url = imageUrl });
        using var content = new StringContent(jsonContent, Encoding.UTF8, "application/json");

        var response = await client.PostAsync(requestUrl, content);
        var responseString = await response.Content.ReadAsStringAsync();

        Console.WriteLine("Analysis Result:");
        Console.WriteLine(responseString);
    }
}
```
