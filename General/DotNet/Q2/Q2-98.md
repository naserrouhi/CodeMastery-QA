# Q2-98: What are Containers? Explain Docker.

- Containers are lightweight, standalone, and portable virtualized environments that package applications along with their dependencies (libraries, configurations, etc.).

- They allow applications to run consistently across different environments, from a developer’s laptop to production servers.

- Benefits:

    1. Portability → Run the same application anywhere (development, testing, production).

    2. Isolation → Each container has its own dependencies and environment, preventing conflicts.

    3. Fast Deployment → Containers start quickly and require less overhead than VMs.

- Docker is a containerization platform that helps developers create, deploy, and manage containers easily.

- It provides tools to package applications and their dependencies into Docker images, which can be shared and run anywhere.

- Key Concepts:

    1. Docker Image → A pre-packaged blueprint that includes the app, dependencies, and configurations.

    2. Docker Container → A running instance of a Docker image.

    3. Dockerfile → A script that defines how to build a Docker image.

    4. Docker Hub → A repository for storing and sharing Docker images.

    5. Docker Compose → A tool to define and run multi-container applications.
