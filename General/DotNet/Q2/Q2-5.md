# Q2-5: Which programming paradigm does C# support?

- C# is mainly an OOP language.

- Over time, functional programming features (like LINQ, lambda expressions, and immutability) became very common in C#.

- Many modern C# developers use a mix of OOP, functional, and asynchronous programming in their applications.

- C# can implement all major programming paradigms, either natively or through libraries.

    1. Imperative Programming → Uses loops, conditionals, and explicit instructions (for, if, while).

    2. Procedural Programming → Organizes code into reusable functions (void MyFunction() { }).

    3. Object-Oriented Programming → Uses classes, objects, inheritance, polymorphism (class Car { }).

    4. Functional Programming → Supports higher-order functions, immutability (`Func<int, int> square = x => x * x;`).

    5. Declarative Programming → Used in LINQ, SQL-like queries (var result = list.Where(x => x > 10);).

    6. Event-Driven Programming → Uses event handlers and delegates (button.Click += HandleClick;).

    7. Asynchronous Programming → Supports async/await for non-blocking execution (await Task.Delay(1000);).

    8. Generic Programming → Uses generics to create type-safe reusable components (`List<T>`, `Dictionary<K, V>`).

    9. Logic Programming → Not native, but can be simulated with LINQ expressions or AI rule engines.

    10. Metaprogramming → Uses reflection, expression trees, and source generators.

    11. Reactive Programming → Supported through libraries like Rx.NET (Observable.Interval(TimeSpan.FromSeconds(1));).

    12. Message-Driven Programming → Used in distributed systems via RabbitMQ, Kafka, Azure Service Bus.
