# Q2-96: What's the difference between horizontal scaling and vertical scaling?

Monolotihc vs micrpservice vs distributed monolothic?

1. Horizontal Scaling (Scaling Out)

    - Adding more machines (servers, containers) to distribute the load.
    - Adding more instances of an application.
    - If a web app is slow, adding more servers behind a load balancer.
    - if one server fails, others keep running.
    - Better for handling high traffic loads.
    - More complex infrastructure (e.g., load balancing).

2. Vertical Scaling (Scaling Up)

    - Increasing the power (CPU, RAM, storage) of an existing server.
    - Simpler to manage.
    - More expensive at high scale.
