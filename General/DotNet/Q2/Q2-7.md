# Q2-7: What is Abstraction?

Task:
    - It shows only the essential features of an object and hides the unnecessary details.

Tools:
    - Abstract classes and interfaces define a blueprint for other classes.

Benefits:
    - It allows developers to focus on high-level interactions without worrying about internal details.
    - It simplifies complex systems to read, or complex objects to use, by providing a high-level view.
    - It makes the code easier to maintain and extend, as changes to internal details don't affect the overall structure.
    - It allows parts of a system to be isolated from others. You can change or update one part without affecting others.
    - It promotes reusability, as the same abstract class or interface can be used in different contexts.
    - It enhaces flexibility, since the implementation can be swapped.
