# Q2-109: What is Session?

seession config general example?

- It is a way to store user-specific data across multiple requests.

- It is often used in web applications to maintain user authentication, shopping carts, and preferences.

- How it works?

    1. When a user visits a website, the server creates a session with a unique Session Id.

    2. This Session Id is stored in a cookie (by default) and sent to the client.

    3. On each request, the client sends this Session Id, so the server knows which data belongs to which user.

    4. The session data is stored on the server (in memory, database, or distributed storage).

    5. The session expires after a certain period of inactivity. (20 minutes by default)

- Example:

```csharp
var builder = WebApplication.CreateBuilder(args);

builder.Services.AddSession(options =>
{
    options.IdleTimeout = TimeSpan.FromMinutes(30);
    options.Cookie.HttpOnly = true;
    options.Cookie.IsEssential = true;
});

var app = builder.Build();
app.UseSession();
```

```csharp
HttpContext.Session.SetString("Username", "JohnDoe");
HttpContext.Session.SetInt32("UserId", 123);

var username = HttpContext.Session.GetString("Username");
var userId = HttpContext.Session.GetInt32("UserId");

HttpContext.Session.Remove("Username");
HttpContext.Session.Clear();
```

- Commonly Used AddSession() Options:

    1. IdleTimeout

        - Specifies the maximum amount of time the session can be idle before it expires.

    2. Cookie Configuration

        - Cookie.HttpOnly = true - Prevents client-side JavaScript from accessing the cookie.

        - Cookie.IsEssential = true - Essential for app functionality, even if the user doesn't consent to cookies.

        - Cookie.SecurePolicy = CookieSecurePolicy.Always - Only sends cookie over HTTPS.

        - Cookie.Name = "myAppSession"

        - Cookie.Path = "/myApp" - Specifies the path for which the session cookie is valid. By default, it's set to /, meaning the cookie will be sent with requests to any URL in the app.

        - Cookie.MaxAge = TimeSpan.FromMinutes(60) - Set a max age for the session cookie.

    3. Session Store

        - By default, ASP.NET Core stores session data in memory.

        - If you're running in a load-balanced or distributed environment, you might want to store session data in a distributed cache (e.g., Redis, SQL Server).

    4. SlidingExpiration

        - If set to true, the expiration time will be reset every time a session is accessed, making it last longer as long as the user is active.
