# Q2-33: What is a routin key in RabbitMQ?

- It is a string that is used by RabbitMQ to determine how messages are routed from an exchange to one or more queues.

- Routing Key in Different Exchange Types

    1. Direct Exchange:

        - It is used as an exact match to route messages to queues.

    2. Fanout Exchange:

        - It is ignored.

    3. Topic Exchange:

        - It is used with wildcards to match patterns.

    4. Headers Exchange:

        - It is ignored.
