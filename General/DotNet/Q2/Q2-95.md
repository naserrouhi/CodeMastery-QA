# Q2-95: What's hybrid cloud environment?

- A hybrid cloud is a combination of on-premises (private cloud) and public cloud (like Azure) infrastructure that allows data and applications to move between them.

- Businesses can move data and applications between both environments as needed.

- Keep sensitive data on-premises while using the cloud for other tasks.

- Handle high traffic by temporarily shifting workloads to the cloud.

- Example: A banking system keeps customer data on-premises for security reasons but uses Azure for running machine learning models to detect fraud.

- On-Premises (On-Prem) refers to IT infrastructure (servers, storage, networking, etc.) that is physically located within a company’s own facilities.
