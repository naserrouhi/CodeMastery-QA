# Q2-59: What's Cryptography?

- It is the practice of securing communication and information by transforming it into a format that is unreadable to unauthorized users.

- It uses mathematical algorithms to protect data.

- Main Goals:

    1. Confidentiality: Ensuring that only authorized parties can read the data (e.g., encrypting messages).

    2. Integrity: Ensuring that the data has not been altered during transmission (e.g., using hash functions).

    3. Authentication: Verifying the identity of users or systems (e.g., using digital signatures).

    4. Non-repudiation: Ensuring that once a transaction is made, the sender cannot deny it (e.g., using digital signatures).

- Types:

    1. Symmetric Cryptography
    2. Asymmetric Cryptography
    3. Hashing
