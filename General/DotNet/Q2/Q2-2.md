## Q2-2: What is a programming paradigm?

- It is a style or way of writing code that defines how programs are structured and executed.

- It provides rules and patterns for organizing logic, managing data, and solving problems.

- Different paradigms influence how programmers think about and design their programs.

- C# support multiple paradigms so you can mix them as needed.


- Types of Programming Paradigms

    1. Imperative Programming
    
        - Focuses on how to do things (step-by-step instructions).
        - Pros: Clear control flow
        - Cons: More complex for large systems

    2. Declarative Programming
    
        - Focuses on what to do, not how to do it.
        - Pros: Less code, easier to read
        - Cons: Less control over execution

    3. Object-Oriented Programming
    
        - Organizes code into objects with properties and behaviors.
        - Pros: Code reusability, modular design
        - Cons: Can be complex for simple tasks

    4. Functional Programming
    
        - Uses pure functions, immutability, and avoids changing states.
        - Pros: Less side effects, easier to debug
        - Cons: Not intuitive for OOP-based developers

    5. Procedural Programming
    
        - A subset of imperative programming that organizes code into procedures (functions).
        - Pros: Simple and easy to understand
        - Cons: Not scalable for large applications


- Which Paradigm to Use?

    - Large, maintainable systems → OOP
    - Mathematical or data transformation tasks → FP
