# Q2-1: What is OOP?

- It is a programming paradigm based on the concept of objects. These objects bundle data (fields/properties) and behavior (methods) together.

- Purpose
  - Helps manage complexity
  - Reuse code
  - Model real-world entities

- Key Principles of OOP:

    1. Encapsulation
    2. Abstraction
    3. Inheritance
    4. Polymorphism
