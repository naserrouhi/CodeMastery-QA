# Q2-29: Explain RPC communication pattern in RabbitMQ?

What is RPC in general?

- RPC (Remote Procedure Call) allows a client to request a service from a remote system as if it were a local function call.

- In RabbitMQ, RPC is implemented using messaging, where a client sends a request message and waits for a response from the server. (It is async)

- Request-Reply Pattern (Basic RPC)

    - It is the most common pattern in RPC commiunication in RabbitMQ.

    - It involves:

        - A client sending a request message to a queue.
        - A server processing the request and sending back a response.
        - The client waiting for the response.

    - In the Request-Reply pattern, we need two queues:

        1. Request Queue: Where the client (producer) sends requests.
        2. Reply Queue: Where the server (consumer) sends back the response.

    - This is because RabbitMQ is asynchronous. The client cannot simply call a function and wait for a return value. Instead, it:

        - Sends a request to a queue.
        - Waits for a response in a separate queue.

    - A Correlation Id is a unique identifier for each request. It helps the client match a response with the correct request.

- Client (Requester):

```csharp
class RPCClient
{
    static void Main()
    {
        var factory = new ConnectionFactory() { HostName = "localhost" };
        using (var connection = factory.CreateConnection())
        using (var channel = connection.CreateModel())
        {
            var requestQueue = "rpc_queue";

            // Declare a temporary exclusive queue for replies
            var replyQueue = channel.QueueDeclare(queue: "", exclusive: true);
            var correlationId = Guid.NewGuid().ToString();

            var props = channel.CreateBasicProperties();
            props.ReplyTo = replyQueue.QueueName;
            props.CorrelationId = correlationId;

            var message = "10";
            var body = Encoding.UTF8.GetBytes(message);

            channel.BasicPublish("", requestQueue, props, body);
            Console.WriteLine($"Sent request: {message}");

            var consumer = new EventingBasicConsumer(channel);
            consumer.Received += (model, ea) =>
            {
                if (ea.BasicProperties.CorrelationId == correlationId)
                {
                    string response = Encoding.UTF8.GetString(ea.Body.ToArray());
                    Console.WriteLine($"Received response: {response}");
                }
            };

            channel.BasicConsume(queue: replyQueue.QueueName, autoAck: true, consumer: consumer);

            Console.WriteLine("Waiting for response...");
            Console.ReadLine();
        }
    }
}
```

- Server (Responder):

```csharp
class RPCServer
{
    static void Main()
    {
        var factory = new ConnectionFactory() { HostName = "localhost" };
        using (var connection = factory.CreateConnection())
        using (var channel = connection.CreateModel())
        {
            var requestQueue = "rpc_queue";
            channel.QueueDeclare(queue: requestQueue, durable: false, exclusive: false, autoDelete: false);

            var consumer = new EventingBasicConsumer(channel);
            consumer.Received += (model, ea) =>
            {
                var message = Encoding.UTF8.GetString(ea.Body.ToArray());
                var n = int.Parse(message);
                Console.WriteLine($"Received request: {n}");

                var response = n * n;

                var replyProps = channel.CreateBasicProperties();
                replyProps.CorrelationId = ea.BasicProperties.CorrelationId;

                var responseBytes = Encoding.UTF8.GetBytes(response.ToString());
                channel.BasicPublish("", ea.BasicProperties.ReplyTo, replyProps, responseBytes);
            };

            channel.BasicConsume(queue: requestQueue, autoAck: true, consumer: consumer);
            Console.WriteLine("RPC Server is running...");
            Console.ReadLine();
        }
    }
}
```
