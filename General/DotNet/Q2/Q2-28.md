# Q2-28: Why stablishing a connection in RabbitMQ is expensive?

What is socket?
What are ports and buffers?
What are Encryption, TLS, SSL?

1. Network Overhead
   - Establishing a TCP connection involves a three-way handshake (SYN, SYN-ACK, ACK) between the client and server. This process takes time and uses network resources.

   - Each connection requires a unique socket, which consumes network ports and buffers.

2. Memory Usage
   - Client Side: The client library (e.g., .NET RabbitMQ client) allocates memory for buffers, state tracking, and connection management.

   - Server Side: RabbitMQ allocates memory for each connection to track its state, manage buffers, and handle communication.

3. CPU Usage
   - Encryption: If the connection is secured with TLS/SSL, encrypting and decrypting data requires significant CPU resources.

   - Connection Management: Both the client and server use CPU cycles to manage the connection, including:
     - Heartbeats (to check if the connection is alive).
     - Error handling.
     - Protocol negotiation (e.g., AMQP protocol).
