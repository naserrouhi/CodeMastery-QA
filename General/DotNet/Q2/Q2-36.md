# Q2-36: What is the three-way handshake?

TCP?
ISN?

- It is a process used to establish a reliable connection between a client and a server in the Transmission Control Protocol (TCP), which is one of the main protocols used in networking.

- It ensures that both parties are ready to exchange data and are synchronized.

- Steps:

    1. SYN (Synchronize)

        - The client sends a synchronize message to the server.
        - The SYN message includes a random initial sequence number (ISN) to start the connection.


    2. SYN-ACK (Synchronize-Acknowledge)

        - The server responds by sending a SYN-ACK message back to the client.
        - The server also includes its own ISN to indicate where the data will start from its side.

    3. ACK (Acknowledge)

        - The client sends an ACK message back to the server, confirming that it has received the server's SYN-ACK message.
        - After this, both the client and the server are synchronized and can start sending data.
