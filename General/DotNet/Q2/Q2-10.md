## Q2-10: What is an Interface?

It is a contract that defines a set of members (methods, properties, events, indexers) that an object must implement.

- Interface Characteristics

    - General Rules
        - Cannot have instance fields.
        - Cannot have constructors.
        - Members are public by default.
        - A class can implement multiple interfaces.
        - An interface can derive from multiple interfaces.
        - Static classes cannot implement an interface.

    - Static Members in Interfaces
        - Can have static fields.
        - Can have static properties.
        - Can have static methods with default implementations.
        - Static members must be initialized, except abstrac methods.
        - The `abstract` keyword is only used for static abstract methods.

    - Default Implementations
        - Instance properties and methods can have default implementations.
        - Access modifiers are not supported on members, except for methods with default implementations.
        - The `virtual` and `override` keywords are not used for interface members or their implementations.

    - Derived Interfaces
        -A derived interface can change the implementation of its parent interface.

```csharp
public interface IBaseInterface
{
    // Instance method with default implementation
    void Display()
    {
        Console.WriteLine("Default implementation of Display in IBaseInterface.");
    }

    // Instance property with default implementation
    string Message { get => "Default message from IBaseInterface."; }

    // Static field
    static int StaticField = 10;

    // Static property
    static string StaticProperty { get; set; } = "Static Property in IBaseInterface.";

    // Static method with default implementation
    static void StaticMethod()
    {
        Console.WriteLine("Static method in IBaseInterface.");
    }

    // Static abstract method (requires implementation in derived interfaces or classes)
    static abstract void StaticAbstractMethod();
}

// Derived Interface
public interface IDerivedInterface : IBaseInterface
{
    // Changing the implementation of the parent interface's default method
    void IBaseInterface.Display()
    {
        Console.WriteLine("Overridden implementation of Display in IDerivedInterface.");
    }

    // Static abstract method implementation
    static void IBaseInterface.StaticAbstractMethod()
    {
        Console.WriteLine("Static abstract method implemented in IDerivedInterface.");
    }
}
```
