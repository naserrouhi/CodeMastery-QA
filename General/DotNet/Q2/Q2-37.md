# Q2-37: What is ISN?

- ISN (Initial Sequence Number) is a random number assigned to the first byte of data in a new TCP connection.

- It helps ensure reliable data transmission and protects against security threats like packet spoofing.

- Packet spoofing is a cyberattack where an attacker fakes (spoofs) the IP address and sequence numbers of network packets to impersonate a trusted device.

- Importance;

    1. Tracks Data Order → TCP is a reliable protocol, so each byte of data is assigned a sequence number.

    2. Prevents Duplicate Connections → If ISNs were predictable, an old connection's data could be mistaken for a new connection's data.

    3. Security → A predictable ISN could allow attackers to hijack TCP sessions.

- Generation:
  
  - The ISN is generated using a randomization algorithm, which changes over time.

  - Older systems used incremental ISNs (e.g., ISN = previous ISN + 1), which made them easy to guess.

  - Modern systems use pseudo-random number generators (PRNGs) or cryptographic algorithms to ensure ISNs are unpredictable.

  - Only the first sequence number (ISN) is random, but after that, TCP increases it sequentially (by 1 for each byte of data sent).
