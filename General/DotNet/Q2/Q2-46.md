# Q2-46: What's the difference between bit and byte?

1. Bit (binary digit)

    - It is the smallest unit of data in computing.
    - It can have only two possible values: 0 or 1.
    - Bits are used to represent a single binary value or a state (true/false).
    - The speed of data transfer is measured in bits per second (bps).

2. Byte

    - byte = 8 bits
    - It is the standard unit for storage and memory measurement.
    - It is typically used to represent a single character in text.

- We use bits to measure network speed because:

    1. Bits are the smallest unit of data, so they provide a more precise way to measure speed.

    2. It's the standard in networking.

    3. Network equipment like routers and modems typically work with bits.
