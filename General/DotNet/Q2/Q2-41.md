# Q2-41: What is a TCP segment?

- It is a unit of data sent over a TCP connection.

- Sections of a TCP Segment: Header and Payload

1. TCP Header

    - It is a fixed-size section (20–60 bytes) at the beginning of every TCP segment.

    - It contains metadata needed to manage the connection and data delivery.

    - Important Fields:

        - Source Port & Destination Port
        - Sequence Number
        - Acknowledgment Number
        - Flags
        - Window Size
        - Checksum

2. Payload

    - The actual message or file being sent.
    - The payload size depends on network conditions (Max ~64 KB).
