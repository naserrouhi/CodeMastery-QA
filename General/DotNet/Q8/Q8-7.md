# Q8-7: What are HTTP Status Codes?

- 2xx – Success

| Code           | Meaning                               | Use Case                               |
| -------------- | ------------------------------------- | -------------------------------------- |
| 200 OK         | Request succeeded                     | Standard GET, PUT, PATCH responses     |
| 201 Created    | Resource created                      | POST /users                            |
| 202 Accepted   | Request accepted for async processing | Long-running operations                |
| 204 No Content | Success but no body                   | DELETE success, PUT/PATCH without body |

- 3xx – Redirection

| Code                  | Meaning                     | Use Case                             |
| --------------------- | --------------------------- | ------------------------------------ |
| 301 Moved Permanently | Resource URL changed        | Permanent API version move           |
| 302 Found             | Temporary redirect          | Rare in APIs                         |
| 304 Not Modified      | Cached resource still valid | Conditional GET with `If-None-Match` |

- 4xx – Client Errors

| Code                       | Meaning                              | Use Case                       |
| -------------------------- | ------------------------------------ | ------------------------------ |
| 400 Bad Request            | Invalid syntax or missing parameters | Wrong JSON format              |
| 401 Unauthorized           | Missing/invalid authentication       | No token, bad token            |
| 403 Forbidden              | Authenticated but not allowed        | Role restrictions              |
| 404 Not Found              | Resource not found                   | GET /users/999                 |
| 405 Method Not Allowed     | Wrong HTTP method used               | DELETE on a read-only endpoint |
| 409 Conflict               | Resource state conflict              | Duplicate email during signup  |
| 410 Gone                   | Resource permanently removed         | Deleted API resource           |
| 415 Unsupported Media Type | Wrong `Content-Type`                 | Sending XML to JSON API        |
| 422 Unprocessable Entity   | Validation error                     | Field format wrong             |
| 429 Too Many Requests      | Rate limit exceeded                  | API throttling                 |

- 5xx – Server Errors

| Code                      | Meaning                       | Use Case                 |
| ------------------------- | ----------------------------- | ------------------------ |
| 500 Internal Server Error | Unexpected failure            | Null reference exception |
| 502 Bad Gateway           | Upstream server error         | API gateway timeout      |
| 503 Service Unavailable   | Server overloaded/maintenance | Retry after maintenance  |
| 504 Gateway Timeout       | Timeout from upstream         | DB query too slow        |
