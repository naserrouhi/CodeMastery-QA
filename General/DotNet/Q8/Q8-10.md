# Q8-10: What are the differences between REST, REST API and RESTful?

- REST:

    - An architectural style for designing networked applications.
    - Principles: statelessness, client-server separation, cacheable responses, uniform interface, layered system, optional HATEOAS.

- REST API:

    - An actual implementation of REST principles using HTTP.
    - May or may not be fully compliant with every REST constraint.

- RESTful API:

    - A REST API that fully follows REST principles.
    - Includes proper use of HTTP methods, status codes, statelessness, and ideally HATEOAS.
