# Q8-9: What is HATEOAS?

- HATEOAS (Hypermedia As The Engine Of Application State) is a REST constraint.
- Where the API provides hyperlinks in its responses to guide the client on what actions are possible next.
- While it improves discoverability, in most production APIs we rely on good documentation instead.

- Why it matters:

    - Makes APIs self-discoverable.
    - Reduces the need for hardcoded endpoint knowledge in clients.
    - Improves API evolvability — clients follow links instead of constructing URLs.

- Example:

    - Without HATEOAS:
        - Client needs to know `/products/123/reviews` exists from documentation.

```json
{
  "id": 123,
  "name": "Laptop",
  "price": 1200
}
```

    - With HATEOAS:
        - Now the API tells the client what it can do next and where to do it. 

```json
{
  "id": 123,
  "name": "Laptop",
  "price": 1200,
  "_links": {
    "self": { "href": "/products/123" },
    "update": { "href": "/products/123", "method": "PUT" },
    "delete": { "href": "/products/123", "method": "DELETE" },
    "reviews": { "href": "/products/123/reviews" }
  }
}
```
