# Q8-8: What is the difference between URL and URI?

- URI (Uniform Resource Identifier)

    - A string that uniquely identifies a resource.
    - Can be a locator (where it is), a name (what it is), or both.
    - It is a generic identifier for a resource, which may or may not describe how to access it.

- URL (Uniform Resource Locator)

    - A type of URI that specifies how to locate the resource (includes protocol, domain, path, etc.).
    - It is a specific type of URI that tells you where the resource is located and how to get it.

- Example:

```plaintext
URI: urn:isbn:0451450523               # A book’s ISBN (name only, no location)
URL: https://example.com/products/123  # Location + protocol to access
```
