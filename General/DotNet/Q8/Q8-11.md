# Q8-11: What is a Protocol?

- It is an agreed set of rules for how two systems communicate
- How to format data, how to start and end a conversation, how to handle errors, etc.
- Examples: HTTP, FTP, SMTP, TCP

- When you call:

```csharp
var response = await httpClient.GetAsync("https://example.com");
```

- You’re using the HTTP protocol to communicate with a server.
- Underneath, HTTP itself runs over TCP protocol.
- If it was gRPC, you’d use HTTP/2 protocol.
