# Q8-2: What is GraphQL?

- It is a query language and runtime for APIs, developed by Facebook.
- Unlike REST, which exposes multiple endpoints, GraphQL exposes a single endpoint, and the client asks for exactly what it needs.
- A query language for APIs that lets clients ask for specific data.

- Example

  - With REST:

```http
GET /books/1
```

```json
{
  "id": 1,
  "title": "C# in Depth",
  "authorId": 42,
  "published": "2022-01-01"
}
```

- Now you must call `/authors/42` to get the author info.

  - With GraphQL:

```graphql
query {
  book(id: 1) {
    title
    published
    author {
      name
      nationality
    }
  }
}
```

- Implementation

```bash
dotnet add package HotChocolate.AspNetCore
```

```csharp
public class Book
{
    public int Id { get; set; }
    public string Title { get; set; }
    public Author Author { get; set; }
}

public class Query
{
    public Book GetBook(int id) => BookStore.GetById(id);
}

builder.Services
    .AddGraphQLServer()
    .AddQueryType<Query>();

app.MapGraphQL();
```

```graphql
query {
  book(id: 1) {
    title
    author {
      name
    }
  }
}
```

- Use when:

  - Clients need custom data shapes.
  - You want efficient nested data retrieval.
  - Your frontends require low bandwidth.
  - You're building rich UI dashboards.

- When GraphQL May Be Overkill:

  - For simple CRUD APIs.
  - If you rely on HTTP caching (GET).
  - When learning curve or tooling is a concern.
