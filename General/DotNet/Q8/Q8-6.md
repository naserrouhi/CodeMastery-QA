# Q8-6: What is HTTP Method Choice for Activate & Soft Delete?

- Activate API (`isActive = true/false`)

    - PATCH: because you are updating only the isActive property.
    - Response: 200 OK

- Soft Delete API (`isDeleted = true`)

    - DELETE: because from the client's perspective, the resource is “gone.”
    - Response: 204 No Content
