# Q7-2: What are IDisposabe and IAsyncDisposable?

- It is an interface used to release unmanaged resources manually when you're done with them.
- When a class implements `IDisposable`, you can use it inside a `using` block, which automatically calls `Dispose()` when done.
- `IAsyncDisposable` introduced for asynchronously cleaning up resources.

```csharp
public interface IDisposable
{
    void Dispose();
}

public interface IAsyncDisposable
{
    ValueTask DisposeAsync();
}
```

```csharp
public class MyAsyncResource : IAsyncDisposable
{
    private readonly StreamWriter _writer;

    public MyAsyncResource(string path)
    {
        _writer = new StreamWriter(path);
    }

    public async Task WriteLineAsync(string text)
    {
        await _writer.WriteLineAsync(text);
    }

    public async ValueTask DisposeAsync()
    {
        await _writer.FlushAsync();
        await _writer.DisposeAsync();
    }
}
```

- Benefits:

  - clean up unmanaged resources
  - close external connections (files, DB, network)
  - avoid memory leaks
  - follow deterministic cleanup — not wait for GC

- Common Mistakes

| Mistake                                            | Why it's a problem                                 |
| -------------------------------------------------- | -------------------------------------------------- |
| Forgetting to call `Dispose()`                     | Causes file locks, memory leaks, exhausted DB pool |
| Disposing same object twice manually               | May cause ObjectDisposedException                  |

- Unmanged resources implement the `IDisposable` pattern to clean up unmanaged OS-level handles.

  1. Releases any managed resources.
  2. Closes low-level DB handles (unmanaged) by calling native methods. (like `CloseHandle`, `SQLFreeHandle`, etc.)

```csharp
public void Dispose()
{
    Dispose(true);
    GC.SuppressFinalize(this);
}

protected virtual void Dispose(bool disposing)
{
    if (disposing)
    {
        // Free managed resources (e.g., internal timers, managed buffers)
    }

    // Free unmanaged resources (e.g., native handles, DB connection handles)
}
```
