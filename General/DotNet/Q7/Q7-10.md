# Q7-10: What is IAsyncEnumerator?

- It is for asynchronously iterating over a stream of data — ideal for things like:

  - Streaming large result sets from a DB
  - Paginated API calls
  - Reading lines from a file/network stream

- It’s like `IEnumerator<T>` (for `foreach`), but it’s asynchronous.

```csharp
await foreach (var item in GetItemsAsync())
{
    Console.WriteLine(item);
}
```

- Example

```csharp
public async IAsyncEnumerable<int> GetNumbersAsync()
{
    for (var i = 0; i < 5; i++)
    {
        await Task.Delay(500);
        yield return i;
    }
}

await foreach (var num in GetNumbersAsync())
{
    Console.WriteLine(num);
}
```

- Interface Definition

```csharp
public interface IAsyncEnumerable<out T>
{
    IAsyncEnumerator<T> GetAsyncEnumerator(CancellationToken cancellationToken = default);
}

public interface IAsyncEnumerator<out T> : IAsyncDisposable
{
    ValueTask<bool> MoveNextAsync();
    T Current { get; }
}
```

- Use Cases

| Scenario                | Why `IAsyncEnumerable<T>` is great    |
| ----------------------- | ------------------------------------- |
| Database streaming      | Avoids loading everything into memory |
| APIs with pagination    | Fetches pages as needed               |
| Network/file stream     | Reads line-by-line or chunk-by-chunk  |
| Kafka/event consumption | Async event loop style processing     |

- Questions

| Question                                             | Tip Answer                                              |
| ---------------------------------------------------- | ------------------------------------------------------- |
| Can you use `foreach` with async methods?            | No — must use `await foreach`                           |
| Can `IAsyncEnumerable<T>` be cancelled?              | Yes — supports `CancellationToken`                      |
| Can `yield return` be used with `async`?             | Yes — if the method returns `async IAsyncEnumerable<T>` |
| Is `IAsyncEnumerator<T>` disposable?                 | Yes — implements `IAsyncDisposable`                     |
| Can you iterate multiple times over an async stream? | Not guaranteed — often one-time-use                     |

- Common Pitfalls

| Pitfall                               | Why it's bad                |
| ------------------------------------- | --------------------------- |
| Forgetting `await` in `await foreach` | Compiler error              |
| Assuming it buffers all results       | It streams items one-by-one |
