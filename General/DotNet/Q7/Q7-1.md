# Q7-1: What is Using?

- it is a keyword that ensures that an object is disposed properly, even if an exception occurs.
- It guarantees that `Dispose()` is called, not that the object is garbage collected.

- It's mostly used with objects that access unmanaged resources, like:
  - Files (`FileStream`, `StreamReader`)
  - Database connections (`SqlConnection`)
  - Network streams
  - `HttpClient` (or manage with `IHttpClientFactory`)
  - Anything implementing `IDisposable`

- Example

```csharp
using (var resource = new MyDisposable())
{
}
```

Is equivalent to:

```csharp
var resource = new MyDisposable();

try
{
}
finally
{
    if (resource != null)
        resource.Dispose();
}
```

- Common Misunderstandings

| Mistake                                                       | Why It's Wrong                                 |
| ------------------------------------------------------------- | ---------------------------------------------- |
| Thinking `using` handles/logs exceptions                      | It doesn’t — it only cleans up after exception |
| Forgetting to use `using` for `SqlConnection` or `FileStream` | May cause memory leaks or locked files         |
| Using `using` on a type that doesn’t implement `IDisposable`  | Compile-time error                             |
