# Q7-3: What are Unmanaged Resources?

- These are resources not managed by the .NET Garbage Collector, such as:

| Resource                     | Example                                       |
| ---------------------------- | --------------------------------------------- |
| File handles                 | `FileStream`, `StreamReader`                  |
| Network sockets              | `TcpClient`, `Socket`                         |
| Database connections         | `SqlConnection`                               |

- Why Are Some Resources Unmanaged?

  - Because they are outside the control of the .NET runtime and garbage collector.
  - Because they are part of the OS or external systems, outside .NET.
  - Some resources that your code uses are not managed by the CLR.
  - GC has no idea how to release a file on disk or close a socket.
