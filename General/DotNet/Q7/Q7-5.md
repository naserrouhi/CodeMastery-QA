# Q7-5: What is async?

- The `async` modifier tells the compiler this method will use asynchronous programming with the `await` keyword.
- It enables non-blocking execution — while waiting, control returns to the caller.

- Key Rules:

  - An `async` method must return `Task`, `Task<T>`, `ValueTask<T>`, or `void`
  - Must have at least one `await` inside to actually be asynchronous
  - If no `await`, method runs synchronously — this is a common bug

- Questions:

| Question                                                      | Correct Answer                                                      |
| ------------------------------------------------------------- | ------------------------------------------------------------------- |
| What happens if I forget to use `await` in an `async` method? | Method runs synchronously, returns an unstarted task                |
| Can I use `async void`?                                       | Only in event handlers, not business logic — can’t catch exceptions |
| What if I return `void` from an `async` method?               | You lose control over exceptions or completion                      |
| Is `async` itself multithreading?                             | No — it's about asynchronous I/O, not threads                       |
