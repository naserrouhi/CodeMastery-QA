# Q7-13: What is Syntactic Sugar?

- It means a nicer or simpler way to write code that the compiler turns into something more complex behind the scenes.
- It doesn't add new features — it just makes your code easier to read and write.
- Instead of writing `"glucose + glucose + ..."` you write `"sugar"`.

- Examples

```csharp
foreach (var item in list)
{
    Console.WriteLine(item);
}

// Compiler turns it into:

using (var enumerator = list.GetEnumerator())
{
    while (enumerator.MoveNext())
    {
        var item = enumerator.Current;
        Console.WriteLine(item);
    }
}
```
