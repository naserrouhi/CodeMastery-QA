# Q5-3: What is List?

- It is a dynamic array — like an array, but it can grow and shrink automatically when you add or remove items.
- It keeps the order of elements.
- It’s type-safe.

- Example:

```csharp
var numbers = new List<int>();

numbers.Add(10);
numbers.Add(20);
numbers.Add(30);

Console.WriteLine(numbers[0]);

numbers.Remove(20);
Console.WriteLine(numbers.Count);

var primes = new List<int> { 2, 3, 5, 7 };
```

- When should you use List<T>?

    - You need to add or remove elements dynamically.
    - You want a collection that keeps order.
    - You don’t know the size in advance.

- Advantages:

    - Dynamic size.
    - Many helper methods (Add, Remove, Insert, Sort, etc.).
    - Type-safe and fast access by index.

- Disadvantages

    - Slower than arrays for raw speed when you don’t need resizing.
    - Slightly more memory overhead than arrays.
    - Removing from the middle shifts all later elements (linear time).

- Tricks:

- Capacity vs Count

    - Count is how many elements are currently in the list.
    - Capacity is how much space is allocated internally.

```csharp
var list = new List<int>();
Console.WriteLine(list.Count);     // 0
Console.WriteLine(list.Capacity);  // 0 or some default

list.Add(1);
list.Add(2);
Console.WriteLine(list.Count);     // 2
Console.WriteLine(list.Capacity);  // >= 2
```

- Remove(value) removes the first occurrence of the value.
- RemoveAt(index) removes the element at that position.

- If you modify a list (Add, Remove) while looping with foreach, you get an exception.
- Solution: Use a for loop, or collect items to remove in another list and remove them afterward.

```csharp
foreach (var n in list)
    list.Remove(n);  // InvalidOperationException
```

- What’s the difference between Array and List<T>?

     - Array is fixed-size, List<T> resizes dynamically and provides more functionality.

- What happens if you add items beyond capacity?

    - List doubles its internal array size.

```csharp
list.RemoveAll(n => n % 2 == 0);

list.Sort();
```
