# Q5-1: What are the differenct kind of data structures in C#?

- Data structures fall into two main categories:

    - Non-generic (old, in System.Collections)
    - Generic (modern, in System.Collections.Generic)

- I recommend you always prefer generic ones in practice because they are type-safe and faster.

- Summary of differences:

    - Use Array when size is fixed and you want minimal overhead.
    - Use List<T> when you need resizable, ordered collection.
    - Use LinkedList<T> when frequent insertions/removals in the middle.
    - Use Queue<T> for FIFO, Stack<T> for LIFO.
    - Use HashSet<T> when uniqueness is important.
    - Use Dictionary<TKey, TValue> when mapping keys to values.
    - Use sorted versions when order matters.

- Arrays and lists have fast indexing (O(1)), while linked lists are better for frequent insertions/removals but slow to traverse.
