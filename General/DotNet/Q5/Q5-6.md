# Q5-6: What is Stack?

- It is a Last-In-First-Out (LIFO) collection — the last item you add is the first one you get out.

- Think of it like a stack of plates: you put a plate on top and you also take the top plate first.
    - Ordered.
    - Dynamic size.
    - Very fast push and pop.

- Example:

```csharp
var stack = new Stack<string>();

stack.Push("A");
stack.Push("B");
stack.Push("C");

Console.WriteLine(stack.Pop());   // Output: C
Console.WriteLine(stack.Peek());  // Output: B
```

- Push(value) → put item on top of the stack.
- Pop() → remove and return the item from the top.
- Peek() → look at the item on top without removing it.

- When should you use Stack<T>?

    - You need to process items in reverse order of arrival.
    - You want efficient (O(1)) push and pop operations.
    - You don’t care about accessing elements in the middle.

- Advantages:

    - Perfect for LIFO scenarios.
    - Very fast and efficient.
    - Type-safe.

- Disadvantages:

    - No random access.
    - Can only operate on top of the stack.

- Tricks:

- If you call Pop() or Peak() on an empty stack, it throws InvalidOperationException.

```csharp
if (stack.Count > 0)
    stack.Pop();
```

- You cannot do stack[0] — it’s not indexable. Only top item is accessible.

- Use-case for Stack<T>.

    - Undo/redo functionality, parsing expressions, depth-first search (DFS).
