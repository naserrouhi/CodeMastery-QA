# Q5-4: What is LinkedList?

- It is a doubly-linked list — a sequence of nodes, where each node points to the next and the previous node.
- Unlike List<T>, it does not use an array.
- It allows fast insertions/removals if you already have a node reference.
- It keeps the order of elements.

- Example:

```csharp
var linkedList = new LinkedList<int>();

linkedList.AddLast(10);
linkedList.AddLast(20);
linkedList.AddFirst(5);

foreach (var n in linkedList)
    Console.WriteLine(n);
// Output: 5, 10, 20
```

- When should you use LinkedList<T>?

    - You need to add or remove elements in the middle of a list frequently.
    - You don’t care about random access by index.
    - You care about insert/remove performance, not access speed.

- Advantages of LinkedList<T>

    - Very fast insertions/removals if you already have a LinkedListNode<T>.
    - Keeps order.
    - Can insert at beginning, middle, or end efficiently.

- Disadvantages

    - No indexing (can’t quickly access element by position).
    - More memory overhead (each node has two pointers).
    - Slower traversal compared to arrays or lists.

- Tricks:

- Unlike List<T>, you cannot do linkedList[0] — it doesn’t support indexing.
- Instead, you must traverse from the beginning.

```csharp
var node = linkedList.First;
while (node != null)
{
    Console.WriteLine(node.Value);
    node = node.Next;
}
```

- You can insert relative to a specific node:
- This is much faster (O(1)) compared to List<T>, which would shift elements.

```csharp
var node10 = linkedList.Find(10);
linkedList.AddAfter(node10, 15);
linkedList.AddBefore(node10, 7);
```

- Even though insertion/removal is fast, finding a specific value still takes O(n) time — because you must traverse the list.

- What’s the difference between List<T> and LinkedList<T>?

    - List<T> allows fast random access and is better when you mostly add/remove at the end.
    - LinkedList<T> is better when you insert/remove frequently in the middle, and don’t need fast random access.

```csharp
linkedList.Remove(node); //by node
linkedList.Remove(10); //by value
```

- How do you reverse a linked list?

    - You can either write a loop manually, or create a new list and add elements in reverse.
