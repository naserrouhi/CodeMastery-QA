# Q5-10: What is SortedList?

- A SortedList<TKey, TValue> is also a collection of unique key-value pairs, sorted by key,

- But it is implemented differently from SortedDictionary.
    - Unique keys.
    - Keys always sorted.
    - Internally uses two arrays — one for keys, one for values.

- Example:

```csharp
var sortedList = new SortedList<int, string>();

sortedList.Add(3, "Three");
sortedList.Add(1, "One");
sortedList.Add(2, "Two");

foreach (var kvp in sortedList)
    Console.WriteLine($"{kvp.Key}: {kvp.Value}");
// Output:
// 1: One
// 2: Two
// 3: Three
```

- You can also access by index (unlike SortedDictionary):

```csharp
Console.WriteLine(sortedList.Keys[0]);    // 1
Console.WriteLine(sortedList.Values[0]);  // One
```

- When should you use SortedList<TKey, TValue>?

    - You need a sorted key-value collection.
    - You’re working with a small dataset.
    - You want to access by index sometimes.

- Advantages:

    - Keys are always sorted.
    - Fast lookups (O(log n)).
    - Less memory for small data.
    - Indexable by position.

- Disadvantages

    - Slower insert/remove for large datasets.
    - Slower than SortedDictionary at scale.

- Tricks:

- How is SortedList different from SortedDictionary?

    - Both keep keys sorted,
    - Both enforce unique keys.
    - SortedList uses less memory than SortedDictionary for small datasets.
    - SortedList is faster than SortedDictionary on small datasets.
    - SortedList has slower insertion/removal for large datasets (O(n) because it shifts arrays).
    - SortedList allows access by index.
    - On large datasets, SortedDictionary is better because it’s tree-based (O(log n)),
    - While SortedList needs to shift elements in its internal arrays when inserting or removing (O(n)).
    - SortedList uses arrays internally, takes less memory, and allows access by index — but slower for large datasets.

- Keys must be unique.

- Use-case for SortedList:

    - Small, sorted configuration data where order matters and indexing by position is useful.
