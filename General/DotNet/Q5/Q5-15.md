# Q5-15: What is IList?

- An interface that extends ICollection<T> and adds:

    - Access by index (myList[0])
    - Insert/remove at specific positions

- It can Read/write like ICollection.

- Example:

```csharp
IList<int> list = new List<int> {1, 2, 3};
list[1] = 42;        // indexed access
list.Insert(1, 99);  // insert at index
```

- When to use?

    - You need an ordered, indexable collection.
    - You want to pass in something that could be a List, an array, etc.

- Tricks:

- IEnumerable<T>: just iterate
- ICollection<T>: + count, add/remove
- IList<T>: + order, indexing, insert/remove by index

- What’s the difference between IEnumerable<T> and IList<T>?
    
    - IEnumerable is read-only iteration.
    - IList supports random access, insert, remove, modify.

- Only ordered, indexable collections implement IList<T>:

    - List<T>
    - BindingList<T>
    - Collection<T>
    - ObservableCollection<T>
    - Arrays (T[]) implement non-generic IList, but not IList<T>

- So if it’s ordered and lets you do list[0] — it probably implements IList<T>.
