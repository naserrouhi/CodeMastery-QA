# Q5-13: What is IEnumerable?

- It’s not a data structure itself, but an interface that defines:

    - A sequence of elements that you can enumerate one by one.

- All collections that you can foreach implement IEnumerable.
- Very basic, read-only access — you can only iterate.
- Does not guarantee random access or modification.

- Example:

```csharp
IEnumerable<int> sequence = new List<int> {1, 2, 3};

foreach (var x in sequence)
    Console.WriteLine(x);

// Console.WriteLine(sequence[1]);  // ❌ Error: no indexer
```

- Almost all collections in .NET implement IEnumerable:
    
    - Arrays (int[])
    - List<T>
    - HashSet<T>
    - Queue<T>
    - Stack<T>
    - LinkedList<T>
    - SortedSet<T>
    - Dictionary<TKey, TValue> (but you enumerate keys or values or KeyValuePairs)
    - SortedList<TKey, TValue>
    - ConcurrentBag<T>
    - strings (string implements IEnumerable<char>)

- When to use?

    - You only need to iterate through elements.
    - You want to make your method generic and work with any collection.

- Deferred execution: LINQ queries (Where, Select) return IEnumerable and don’t execute until you iterate them.

- What’s the difference between IEnumerable<T> and ICollection<T>?

    - IEnumerable<T> only supports iteration.
    - ICollection<T> adds Count, Add, Remove, etc.
