# Q5-8: What is Dictionary?

- A Dictionary<TKey, TValue> is a collection of key-value pairs, where each key is unique and maps to a value.

- Internally it uses a hash table, so lookups, insertions, and deletions by key are fast (O(1) average).
    - Unique keys.
    - Fast key-based access.
    - No guaranteed order.

- Example:

```csharp
var dict = new Dictionary<int, string>();

dict.Add(1, "One");
dict.Add(2, "Two");
dict[3] = "Three";

Console.WriteLine(dict[2]);

foreach (var kvp in dict)
    Console.WriteLine($"{kvp.Key}: {kvp.Value}");
```

- When should you use Dictionary<TKey, TValue>?

    - You need to associate one value with a unique key.
    - You need fast lookups by key.
    - You don’t care about insertion order.

- Advantages:

    - Very fast lookups and inserts by key.
    - Flexible — keys and values can be any types.
    - Ensures keys are unique.

- Disadvantages:

    - Keys must be unique.
    - Uses more memory than a simple list.
    - No guaranteed order.

- Tricks:

- Trying to add the same key again throws an exception:

```csharp
dict.Add(1, "Another One");  // throws ArgumentException
dict[1] = "Updated";
```

- If you try to access a key that doesn’t exist:

```csharp
Console.WriteLine(dict[4]);  // throws KeyNotFoundException

if (dict.TryGetValue(4, out string value))
    Console.WriteLine(value);
```

- Iteration order is undefined — if order matters, use SortedDictionary.

- What’s the difference between Dictionary<TKey, TValue> and List<T>?

    - Dictionary maps unique keys to values, List is just an ordered sequence of values.

- Use-case for Dictionary.

    - Caching, mapping IDs to objects, storing configuration settings.
