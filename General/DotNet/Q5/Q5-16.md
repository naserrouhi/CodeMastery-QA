# Q5-2: What are Bag and ConcurrentBag?

- Bag<T>:

    - .NET does not have a direct Bag<T> class in the standard library — it comes from some libraries (like PowerCollections).
    - An unordered collection.
    - Allows duplicates.
    - Think of it like a multiset.

- ConcurrentBag<T>?

    - Part of System.Collections.Concurrent.
    - It is a thread-safe, unordered collection that allows duplicates.

- Example:

```csharp
var bag = new ConcurrentBag<int>();
bag.Add(1);
bag.Add(2);
bag.Add(2);

if (bag.TryTake(out int result))
    Console.WriteLine(result);
```

- When to use?

    - You need a thread-safe unordered collection.
    - You want to allow duplicates.
    - You don’t care about order.

- When would you use ConcurrentBag vs ConcurrentQueue?

    - Use ConcurrentBag when you don’t care about order.
    - Use ConcurrentQueue when you need FIFO.
