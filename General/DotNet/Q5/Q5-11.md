# Q5-11: What is SortedSet?

- A SortedSet<T> is a collection of unique elements, just like HashSet<T>,
- But it keeps the elements sorted according to their natural order or a custom comparer.

- Internally it uses a balanced binary search tree (Red-Black tree).
    - Uniqueness.
    - Sorted order.
    - No duplicates allowed.

- Example:

```csharp
var sortedSet = new SortedSet<int>();

sortedSet.Add(3);
sortedSet.Add(1);
sortedSet.Add(2);
sortedSet.Add(2);  // ignored — duplicate

foreach (var n in sortedSet)
    Console.WriteLine(n);
// Output:
// 1
// 2
// 3
```

- You can also use custom sorting:

```csharp
var descendingSet = new SortedSet<int>(Comparer<int>.Create((a, b) => b - a));
```

- When should you use SortedSet<T>?

    - You need a collection of unique elements, like HashSet.
    - But you also care about elements being sorted.

- Advantages:

    - Keeps elements unique.
    - Always sorted.
    - Supports set math operations.

- Disadvantages:

    - Slower than HashSet for large datasets.
    - No indexing (you cannot get item by position).

- Tricks:

- How is SortedSet<T> different from HashSet<T>?
    
    - Both enforce uniqueness.
    - SortedSet keeps elements sorted (O(log n) for add/remove/search).
    - HashSet is unordered and faster (O(1) average for add/remove/search).
    - So if you care about order, use SortedSet. If you care only about speed, use HashSet.
    - Slower than HashSet because of tree (O(log n)), not hash table.
    - Both enforce uniqueness, but SortedSet also keeps elements sorted and is slower than HashSet.

- Adding a duplicate does nothing and returns false.

- Just like HashSet, it supports:

```csharp
    UnionWith()
    IntersectWith()
    ExceptWith()
    IsSubsetOf()
    //etc.
```

- Use-case for SortedSet:
    
    - Storing unique sorted data like leaderboard scores, alphabetically sorted unique words.
