# Q5-2: What is Array?

- It is a fixed-size, ordered collection of items, all of the same type.
- Once you create it, you cannot resize it — it stays the same length.

- Example:

```csharp
int[] numbers = new int[5];
numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;

Console.WriteLine(numbers[0]);

int[] primes = new int[] { 2, 3, 5, 7 };

int[] primes = { 2, 3, 5, 7 };
```

- When should you use Array?

    - Know the number of elements in advance.
    - Need very fast access by index (O(1)).
    - Want to save memory (array has very little overhead).

- Advantages:

    - Fast random access.
    - Very memory-efficient.
    - Easy to use.

- Disadvantages

    - Cannot grow or shrink.
    - Not many built-in helper methods.
    - Not type-safe if you use the old Array class (better to use int[]).

- Tricks:

```csharp
int[] arr = new int[3];
Console.WriteLine(arr[3]);  // Throws IndexOutOfRangeException
```

- What happens if you access arr[-1]? - IndexOutOfRangeException.

- Resizing: use List<T> if you need resizing.

```csharp
int[] oldArr = { 1, 2, 3 };
int[] newArr = new int[5];
Array.Copy(oldArr, newArr, oldArr.Length);
```

- If you create an array of integers, all elements start as 0.
- If it’s an array of reference types, all elements are null.

```csharp
string[] names = new string[3];
Console.WriteLine(names[0]);  // Output: null
```

- What is the difference between int[] and Array class?

    - int[] is a strongly-typed array, while Array is a base class for arrays — you lose type safety if you work with Array.

```csharp
Array.Reverse(myArray);
Array.Sort(myArray);
```
