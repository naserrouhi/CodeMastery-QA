# Q5-2: What is IQueryable?

- It is an interface that extends IEnumerable<T>.
- It represents a queryable data source — meaning, you can build queries against it.
- It’s designed for deferred execution and expression trees.
- When you work with IQueryable<T>, you build a query — like filtering, sorting, joining — but the query is not executed immediately.
- Instead, the query is translated into something else (like SQL if you’re querying a database) and executed later.

- Where is IQueryable<T> used?

    - Most commonly in LINQ to SQL, Entity Framework, or any LINQ provider that translates queries to other languages.
    - Example: When you write dbContext.Users.Where(u => u.Age > 18) in Entity Framework, the result is an IQueryable<User>.
    - The query is converted to SQL and sent to the database only when needed.

- How is it different from IEnumerable<T>?

| Aspect             | IEnumerable<T>                   | IQueryable<T>                           |
| ------------------ | -------------------------------- | --------------------------------------- |
| Query execution    | Executes in-memory (client-side) | Executes on remote source (e.g., DB)    |
| Expression tree    | No                               | Yes (stores the query as an expression) |
| Deferred execution | Yes                              | Yes                                     |
| Suitable for       | In-memory collections            | Remote data sources, databases          |

- IQueryable<T> does NOT implement IList<T> or ICollection<T>.

| Interface      | Supports Indexing | Supports Modification | Supports Query Building |
| -------------- | ----------------- | --------------------- | ----------------------- |
| IEnumerable<T> | No                | No                    | No                      |
| ICollection<T> | No                | Yes                   | No                      |
| IList<T>       | Yes               | Yes                   | No                      |
| IQueryable<T>  | No                | No                    | Yes (query building)    |
