# Q5-2: What is ICollection?

- ICollection<T> is an interface that extends IEnumerable<T>, and adds:

    - A Count property.
    - Add, Remove, Clear.
    - Contains check.
    - CopyTo to copy into an array.

- Almost all standard modifiable collections implement ICollection<T>:

    - List<T>
    - LinkedList<T>
    - HashSet<T>
    - Queue<T>
    - Stack<T>
    - SortedSet<T>
    - Dictionary<TKey, TValue>.KeyCollection
    - Dictionary<TKey, TValue>.ValueCollection
    - ConcurrentBag<T>
    - ConcurrentQueue<T>
    - ConcurrentStack<T>
    - Arrays implement ICollection, though they have fixed size.

- So if you see a collection that you can both iterate and call .Count or .Add() on — it probably implements ICollection<T>.
