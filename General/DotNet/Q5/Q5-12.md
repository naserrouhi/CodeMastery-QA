# Q5-12: What is BitArray?

- It is a compact collection of bits — each element is either true or false.
- It’s used to store a large number of binary values (1s and 0s) in a memory-efficient way.
- It’s part of System.Collections (non-generic).
- Very memory-efficient (uses 1 bit per value instead of 1 byte).
- Great for flags, masks, toggles, or binary logic.

- Example:

```csharp
var bits = new BitArray(5);  // creates 5 bits, all false

bits[0] = true;
bits[3] = true;

foreach (bool bit in bits)
    Console.WriteLine(bit);
// Output: true false false true false
```

- You can also create it from an array of bools or bytes:

```csharp
var bits = new BitArray(new bool[] { true, false, true });
```

- When should you use BitArray?

    - You need to store or work with a lot of true/false values.
    - You care about saving memory.
    - You need to do bit-level operations (AND, OR, XOR, NOT).
    - e.g., toggles, permissions, masks.

Advantages of BitArray

✔ Very memory-efficient for large boolean sets.
✔ Supports bitwise logic.
✔ Lightweight.
Disadvantages

❌ Not generic.
❌ No LINQ or modern collection methods.
❌ No built-in resizing (must create new one).
❌ Slower than a bool[] in most modern systems (due to boxing/unboxing).

- Tricks:

- Just like arrays, BitArray throws IndexOutOfRangeException if you go out of bounds.

- BitArray supports logical operations between two BitArrays of the same size:

```csharp
var a = new BitArray(new[] { true, false, true });
var b = new BitArray(new[] { true, true, false });

a.And(b);  // a becomes { true, false, false }
```

- Other operations:

```csharp
    .Or()
    .Xor()
    .Not()
```

- It’s an older class, not type-safe — only works with booleans, and it’s in System.Collections, not System.Collections.Generic.

- What are alternatives to BitArray?

    - Use bool[] for simplicity.
    - Use int or flags enum for bitmasking when bits are fewer.
    - Use BitVector32 (for small, packed bits — also memory-efficient).

- Can you resize a BitArray?

    - No. You have to create a new one and copy bits.
