# Q4-17: What are DRY, KISS, YANGI, SOC principles?

- DRY:
  - DRY stands for Don't Repeat Yourself.
  - Avoid duplicating code or logic. Extract shared logic into methods, classes, or services.

- KISS (Keep It Simple, Stupid)
  - Write simple, easy-to-understand code. Avoid over-engineering.

- YAGNI (You Aren’t Gonna Need It)
  - Don’t build functionality until it's actually needed.

- SOC (Separation of Concerns)
  - Split application into layers/components with distinct responsibilities (e.g., UI, Service, Repository).
