# Q4-10: What is the Decorator pattern?

- It lets you wrap an object with another object that adds extra functionality — all without modifying the original class.
- It follows Open/Closed Principle.
- Think of it as "stacking features" dynamically.
- The Decorator Pattern lets you add behavior to objects at runtime without modifying their structure.
- It’s ideal for adding features like logging, caching, or formatting in a modular way.

- Real-world analogy:
  
  - Imagine you order a coffee.
  - Then you add milk, then sugar, maybe even chocolate.
  - Each one adds something new, but the original coffee remains untouched.

- Example:

```csharp
public interface IMessage
{
    string GetText();
}

public class SimpleMessage : IMessage
{
    private readonly string _text;

    public SimpleMessage(string text)
    {
        _text = text;
    }

    public string GetText() => _text;
}

public abstract class MessageDecorator : IMessage
{
    protected readonly IMessage _message;

    public MessageDecorator(IMessage message)
    {
        _message = message;
    }

    public abstract string GetText();
}

public class UpperCaseDecorator : MessageDecorator
{
    public UpperCaseDecorator(IMessage message) : base(message) { }

    public override string GetText() => _message.GetText().ToUpper();
}

public class HtmlTagDecorator : MessageDecorator
{
    public HtmlTagDecorator(IMessage message) : base(message) { }

    public override string GetText() => $"<p>{_message.GetText()}</p>";
}

public class PrefixDecorator : MessageDecorator
{
    public PrefixDecorator(IMessage message) : base(message) { }

    public override string GetText() => $"[INFO]: {_message.GetText()}";
}

IMessage message = new SimpleMessage("Hello, world!");
message = new PrefixDecorator(message);
message = new UpperCaseDecorator(message);
message = new HtmlTagDecorator(message);

Console.WriteLine(message.GetText());
```

- Common Use Cases:

  - Logging and tracing
    - Wrap a service to log input/output without touching the original class.

  - Validation pipelines
    - Add extra validators or error wrappers around existing services.

  - Caching
    - Wrap a repository with a caching decorator to store results in memory.

  - Middleware in ASP.NET Core
    - Each middleware wraps the request/response pipeline like decorators.

  - Formatting or preprocessing data
    - Add headers, escape text, sanitize, format dates, etc.
