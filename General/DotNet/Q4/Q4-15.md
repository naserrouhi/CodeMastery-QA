# Q4-15: What are the types of loading in EF?

- Eager Loading

  - You load related data together with the main entity in the same query.
  - Reduces number of queries.
  - Good when you know you'll need the related data.

```csharp
var order = context.Orders
    .Include(o => o.Customer)
    .FirstOrDefault();
```

- Explicit Loading

  - You load related data manually, after the main entity is already loaded.
  - Gives you control over when to load.
  - Good when you only need related data conditionally.
  - You want to delay loading until it's really needed.
  - You want to avoid loading lots of data unless required.

```csharp
var order = context.Orders.First();

context.Entry(order)
    .Reference(o => o.Customer)
    .Load();
```

- Lazy Loading

  - Related data is automatically loaded on access (like a hidden Include()).
  - It’s convenient but risky in large loops (can cause dozens/hundreds of extra queries).

  - To use it in EF Core:
    - Your navigation properties must be virtual.
    - You must install a separate NuGet package: Microsoft.EntityFrameworkCore.Proxies

```csharp
var order = context.Orders.First();
var customerName = order.Customer.Name;

options.UseLazyLoadingProxies();
```

- What is the default?

  - Eager and explicit loading are available by default — and you must use them manually.
