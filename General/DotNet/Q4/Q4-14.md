# Q4-14: What is Database-Agnostic?

- It means that your application is not tightly coupled to a specific database system (like SQL Server, PostgreSQL, or MySQL).

- How do you achieve it?

  - Use Entity Framework Core.
  - Avoid writing raw SQL that only works for a specific vendor.
  - Use abstractions (like DbContext, repositories).
  - Don't rely on vendor-specific features like stored procedures, SQL hints, or special functions.
