# Q4-21: What is the difference between SP and Function?

| Feature            | Function                                                                           | Stored Procedure                          |
| ------------------ | --------------------------------------------------------------------------------   | ----------------------------------------- |
| Returns            | Always returns a value (scalar or table)                                           | Can return zero, one, or many values      |
| Return Type        | Must return a value (using `RETURN`)                                               | Uses `RETURN`, OUT params, or `SELECT`    |
| Side Effects       | Cannot modify database state (DML like `INSERT`, `UPDATE`, `DELETE` not allowed)   | Can modify data (do any DML or DDL)       |
| Transactions       | Cannot start transactions                                                          | Can start, commit, rollback transactions  |
| Input Parameters   | Only input parameters allowed                                                      | Supports input, output, and return values |
| Use in SQL         | Can be used in SELECT, WHERE, JOIN, etc.                                           | Cannot be used in a SELECT directly       |
| Exception Handling | No `TRY...CATCH`                                                                   | Supports `TRY...CATCH`                    |
| Deterministic Use  | Functions must be deterministic to be indexed                                      | SPs are not deterministic — not indexable |
| Execution Plan     | Can be inlined by optimizer                                                        | Executed as a black box                   |

- Example


```sql
-- Scalar Function
CREATE FUNCTION dbo.GetDiscount(@price DECIMAL)
RETURNS DECIMAL
AS
BEGIN
    RETURN @price * 0.9;
END

SELECT Name, dbo.GetDiscount(Price) FROM Products;

-- Stored Procedure
CREATE PROCEDURE dbo.ApplyDiscount
    @ProductId INT,
    @DiscountPercent DECIMAL
AS
BEGIN
    UPDATE Products
    SET Price = Price * (1 - @DiscountPercent)
    WHERE Id = @ProductId;
END

EXEC dbo.ApplyDiscount @ProductId = 5, @DiscountPercent = 0.1;

-- Table-Valued Function
CREATE FUNCTION dbo.GetOrdersByCustomer
(
    @CustomerId INT
)
RETURNS TABLE
AS
RETURN
(
    SELECT OrderId, OrderDate, TotalAmount
    FROM Orders
    WHERE CustomerId = @CustomerId
);

SELECT * FROM dbo.GetOrdersByCustomer(123);
```
