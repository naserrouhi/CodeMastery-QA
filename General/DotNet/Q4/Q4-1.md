# Q4-1: What’s the difference between a Design Pattern and an Anti-Pattern?

- Design Pattern

  - It is a proven, reusable solution to a common problem in software design.
  - It’s like a blueprint that has been tested and found to improve code structure, maintainability, and flexibility.

- Anti-Pattern

  - It is a solution that seems like a good idea at first, but actually leads to bad results: messy code, bugs, tight coupling, or poor performance.
  - Example: The God Object anti-pattern is when one class does too much and knows too much. It becomes hard to maintain, test, and extend.
