# Q3-5: What is ISP?

- Definition:

  - Clients should not be forced to depend on methods they do not use.
  - It’s better to have many small, specific interfaces than one large, general-purpose interface.
  - Split large interfaces into smaller, specific ones.
  - Helps keep the code clean and focused.

- Bad Design:

```csharp
public interface IPaymentMethod
{
    void Pay(decimal amount);
    void Refund(decimal amount);
    void SchedulePayment(DateTime date);
}

public class PayPalPayment : IPaymentMethod
{
    public void Pay(decimal amount)
    {
        Console.WriteLine("Paid via PayPal.");
    }

    public void Refund(decimal amount)
    {
        Console.WriteLine("Refunded via PayPal.");
    }

    public void SchedulePayment(DateTime date)
    {
        throw new NotSupportedException("PayPal does not support scheduling.");
    }
}
```

- Problem:

  - Clients using PayPalPayment must be aware that not all methods are supported.

- Good Design:

```csharp
public interface IPayment
{
    void Pay(decimal amount);
}

public interface IRefundable
{
    void Refund(decimal amount);
}

public interface ISchedulablePayment
{
    void SchedulePayment(DateTime date);
}

public class CreditCardPayment : IPayment, IRefundable, ISchedulablePayment
{
    public void Pay(decimal amount)
    {
        Console.WriteLine("Paid using Credit Card.");
    }

    public void Refund(decimal amount)
    {
        Console.WriteLine("Refunded to Credit Card.");
    }

    public void SchedulePayment(DateTime date)
    {
        Console.WriteLine($"Credit Card payment scheduled for {date}");
    }
}

public class PayPalPayment : IPayment, IRefundable
{
    public void Pay(decimal amount)
    {
        Console.WriteLine("Paid using PayPal.");
    }

    public void Refund(decimal amount)
    {
        Console.WriteLine("Refunded to PayPal.");
    }
}
```
