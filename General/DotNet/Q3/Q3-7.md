# Q3-7: What is the difference between DI and DIP?

- DIP:

  - Dependency Inversion Principle is a design principle.
  - High-level modules should not depend on low-level modules.
  - Both should depend on abstractions (interfaces or abstract classes).
  - The goal is to make code flexible and decoupled.
  - DIP is the principle: "Depend on abstractions, not concrete implementations."

- DI:
  - Dependency Injection is a pattern used to implement DIP.
  - You inject the dependencies (usually via constructor) instead of creating them inside the class.
