# Q3-13: What is boiler plate?

- It refers to code that:

  - Is repetitive, standard, and doesn't change much across projects.
  - You have to write it, but it’s not the core logic — more like setup or glue code.
  - It means: This code is mostly standard, I didn’t invent it, and it’s not unique logic. It just has to be there.

- Examples:

  - Code to configure dependency injection in every ASP.NET Core app (builder.Services.AddControllers(), etc.)
  - Model or DTO classes with just getters and setters.
  - Entity framework configurations.
  - HTML page layout that’s repeated in every page.
