# Q3-10: What is the difference between High-level and Low-level modules?

- High-Level Module

  - Focuses on business rules, core logic, and what the app should do.
  - It answers: "What is the system supposed to accomplish?"
  - Example: A service that processes a payment, sends a notification, or handles a user registration.

- Low-Level Module

  - Focuses on how things get done — like databases, file systems, APIs, sending emails, etc.
  - It answers: "How do we implement the technical steps to achieve a goal?"
  - Example: A class that sends an email, connects to SQL Server, or reads a file from disk.

- Example:

    1. Low-Level:

```csharp
public class CsvExporter
{
    public void Export(string data)
    {
        File.WriteAllText("report.csv", data);
    }
}
```

    2. High-Level:

```csharp
public class ReportService
{
    private readonly CsvExporter _exporter;

    public ReportService(CsvExporter exporter)
    {
        _exporter = exporter;
    }

    public void GenerateReport()
    {
        string reportData = "Revenue: $1000";
        _exporter.Export(reportData);
    }
}
```

- Apply DIP:

```csharp
public interface IExporter
{
    void Export(string data);
}

public class CsvExporter : IExporter
{
    public void Export(string data)
    {
        File.WriteAllText("report.csv", data);
    }
}

public class ReportService
{
    private readonly IExporter _exporter;

    public ReportService(IExporter exporter)
    {
        _exporter = exporter;
    }

    public void GenerateReport()
    {
        string reportData = "Revenue: $1000";
        _exporter.Export(reportData);
    }
}
```
