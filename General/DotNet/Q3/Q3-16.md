# Q3-16: How is startup pipeline?

- What Happens When a Request Hits?

    1. Program.cs starts the app.
    2. Middleware is executed in order (like a pipeline).
    3. The request reaches the endpoint (controller, Razor page, etc.).
    4. Response flows back through the middleware in reverse.

Program.cs
  → Middleware 1 (e.g., Exception handling)
    → Middleware 2 (e.g., Routing)
      → Middleware 3 (e.g., Authentication)
        → Controller/Endpoint
      ← Middleware 3 (Response)
    ← Middleware 2 (Response)
  ← Middleware 1 (Response)

- Example:

```csharp
var builder = WebApplication.CreateBuilder(args);

// 1. Register services
builder.Services.AddControllers();
builder.Services.AddAuthentication();
builder.Services.AddSwaggerGen();

var app = builder.Build();

// 2. Configure middleware pipeline (order matters!)
app.UseMiddleware<CustomLoggingMiddleware>();
app.UseExceptionHandler("/error");
app.UseHttpsRedirection();
app.UseRouting();
app.UseAuthentication();
app.UseAuthorization();
app.UseEndpoints(endpoints =>
{
    endpoints.MapControllers();
});

app.Run();
```

```csharp
public class Startup
{
    // Called by runtime. Used to register services (DI)
    public void ConfigureServices(IServiceCollection services)
    {
        services.AddControllers();
        services.AddAuthentication();
    }

    // Called by runtime. Used to build request pipeline
    public void Configure(IApplicationBuilder app, IWebHostEnvironment env)
    {
        app.UseExceptionHandler("/error");
        app.UseHttpsRedirection();
        app.UseRouting();
        app.UseAuthentication();
        app.UseAuthorization();
        app.UseEndpoints(endpoints =>
        {
            endpoints.MapControllers();
        });
    }
}
```

| Middleware                                          | Role                                                |
| --------------------------------------------------- | --------------------------------------------------- |
| `UseHttpsRedirection`                               | Forces HTTPS                                        |
| `UseRouting`                                        | Matches incoming routes                             |
| `UseEndpoints(MapControllers)`                      | Executes the matching controller/action             |

```csharp
public class LoggingMiddleware
{
    private readonly RequestDelegate _next;

    public LoggingMiddleware(RequestDelegate next) => _next = next;

    public async Task Invoke(HttpContext context)
    {
        Console.WriteLine($"Incoming request: {context.Request.Path}");
        await _next(context);
        Console.WriteLine($"Outgoing response: {context.Response.StatusCode}");
    }
}

app.UseMiddleware<LoggingMiddleware>();
```

- What happens if you put `UseAuthorization` before `UseAuthentication`?
    - Authorization will fail because no identity is set yet.
