# Q3-15: What is SaaS?

- It stands for Software as a Service.
- It’s a model where software is delivered over the internet, and users access it via a web browser without installing or maintaining it.
- Examples: Gmail, GitHub, chatGPT

| Model       | Description                                                      |
| ----------- | ---------------------------------------------------------------- |
| SaaS        | Software delivered via the web                                   |
| PaaS        | Platform for developers to build apps (e.g., Azure App Services) |
| IaaS        | Cloud infrastructure (e.g., virtual machines on AWS EC2)         |
| On-premises | Installed on customer’s own servers (traditional software)       |
