# What is SRP?

Sure! The Single Responsibility Principle (SRP) means that a class should have only one reason to change, i.e., it should only handle one responsibility.

Bad Example (Violates SRP):

public class Invoice
{
    public void CalculateTotal() 
        {
                // Logic to calculate total
                    }

                        public void SaveToDatabase()
                            {
                                    // Logic to save to DB
                                        }

                                            public void PrintInvoice()
                                                {
                                                        // Logic to print invoice
                                                            }
                                                            }

                                                            This Invoice class has three responsibilities:

                                                            Business logic (CalculateTotal)

                                                            Persistence (SaveToDatabase)

                                                            Presentation (PrintInvoice)


                                                            Any change in one responsibility (e.g., database or print format) may affect the others. This is hard to maintain.


                                                            ---

                                                            Good Example (Follows SRP):

                                                            public class Invoice
                                                            {
                                                                public void CalculateTotal()
                                                                    {
                                                                            // Logic to calculate total
                                                                                }
                                                                                }

                                                                                public class InvoiceRepository
                                                                                {
                                                                                    public void Save(Invoice invoice)
                                                                                        {
                                                                                                // Save invoice to DB
                                                                                                    }
                                                                                                    }

                                                                                                    public class InvoicePrinter
                                                                                                    {
                                                                                                        public void Print(Invoice invoice)
                                                                                                            {
                                                                                                                    // Print invoice
                                                                                                                        }
                                                                                                                        }

                                                                                                                        Now:

                                                                                                                        Invoice handles business logic

                                                                                                                        InvoiceRepository handles persistence

                                                                                                                        InvoicePrinter handles presentation


                                                                                                                        Each class has a single responsibility and a single reason to change.

 Sure! Here's a real-world example using a User Registration system:


 ---

 Bad Example (Violates SRP):

 public class UserService
 {
     public void Register(string username, string password)
         {
                 // 1. Validate data
                         if (string.IsNullOrEmpty(username) || password.Length < 6)
                                     throw new Exception("Invalid data");

                                             // 2. Save user to database
                                                     // (fake DB logic)
                                                             Console.WriteLine("User saved");

                                                                     // 3. Send welcome email
                                                                             Console.WriteLine("Welcome email sent");
                                                                                 }
                                                                                 }

                                                                                 Problem:
                                                                                 UserService has three responsibilities:

                                                                                 1. Validation


                                                                                 2. Persistence


                                                                                 3. Sending email



                                                                                 Any change in email format or storage method will affect this class.


                                                                                 ---

                                                                                 Good Example (Follows SRP):

                                                                                 public class UserValidator
                                                                                 {
                                                                                     public void Validate(string username, string password)
                                                                                         {
                                                                                                 if (string.IsNullOrEmpty(username) || password.Length < 6)
                                                                                                             throw new Exception("Invalid data");
                                                                                                                 }
                                                                                                                 }

                                                                                                                 public class UserRepository
                                                                                                                 {
                                                                                                                     public void Save(string username, string password)
                                                                                                                         {
                                                                                                                                 Console.WriteLine("User saved");
                                                                                                                                     }
                                                                                                                                     }

                                                                                                                                     public class EmailService
                                                                                                                                     {
                                                                                                                                         public void SendWelcomeEmail(string username)
                                                                                                                                             {
                                                                                                                                                     Console.WriteLine("Welcome email sent");
                                                                                                                                                         }
                                                                                                                                                         }

                                                                                                                                                         public class UserService
                                                                                                                                                         {
                                                                                                                                                             private readonly UserValidator _validator = new UserValidator();
                                                                                                                                                                 private readonly UserRepository _repository = new UserRepository();
                                                                                                                                                                     private readonly EmailService _emailService = new EmailService();

                                                                                                                                                                         public void Register(string username, string password)
                                                                                                                                                                             {
                                                                                                                                                                                     _validator.Validate(username, password);
                                                                                                                                                                                             _repository.Save(username, password);
                                                                                                                                                                                                     _emailService.SendWelcomeEmail(username);
                                                                                                                                                                                                         }
                                                                                                                                                                                                         }

                                                                                                                                                                                                         Now:

                                                                                                                                                                                                         UserValidator handles validation

                                                                                                                                                                                                         UserRepository handles storage

                                                                                                                                                                                                         EmailService sends emails

                                                                                                                                                                                                         UserService just coordinates


                                                                                                                                                                                                         Each class has one reason to change, making it easier to maintain and test.
