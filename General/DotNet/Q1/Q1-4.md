# Q1-4: What are stack and heap?

Stack and heap are two places where data is stored in memory.

- **Stack (Small and Fast)**

- It stores method calls, value type variables and the reference of reference type varibales.

- Works like a stack of plates (LIFO).

- When a method is called, the following things are stored in the stack ("stack frame" or "call stack"):

    1. Method arguments
    2. Local variables (inside the method).
    3. Return addresss

- When a method finishes, its data is removed automatically.

- Very fast but has limited space.

- **Heap (Big and Slower)**

- Stores the value of reference type variables.

- Used for big objects that stay in memory longer.

- Needs garbage collection to clean up unused objects.

- Slower than stack but has more space.
