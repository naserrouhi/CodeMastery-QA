## Q1-18: What are ! and ^ operators?

1. Null-forgiving Operator (!)

    - Used after a nullable reference type to suppress compiler warnings about possible null values.

    - Does not change runtime behavior! It only tells the compiler: "Trust me, this isn't null."

2. Index-from-End (^)

    - Used in arrays or collections to get elements from the end.

```csharp
var numbers = { 10, 20, 30, 40, 50 };
Console.WriteLine(numbers[^2]); //40
```
