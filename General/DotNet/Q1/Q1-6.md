# Q1-6: Why strings are reference type?

- Strings are Immutable means that once a string is created, its value cannot be changed.

- When you change the value of a string variable, .NET creates a new string and stores it in the heap. The reference remains but th value changes and the old value makes garbage.

- String Interning:
.NET uses string interning, which means that identical string values are stored only once in memory. This reduces memory usage.

When you create a string, it is stored in a special memory area called the intern pool. If you create the same string again, .NET just points to the same memory location instead of creating a new string.

Intern pool is not exactly part of the regular heap; it's a special memory region managed by the .NET runtime, often separate from the heap.

```csharp
var a = "x";
var b = "x";

var c = Object.ReferenceEquals(a, b); //True
```

```csharp
var a = new string("x".ToCharArray());
var b = new string("x".ToCharArray());

var c = Object.ReferenceEquals(a, b); //False
```

```csharp
var a = "x";
var b = a;

var c = Object.ReferenceEquals(a, b); //true
```

```csharp
var a = "x";
var b = a;
a = "y";

var c = Object.ReferenceEquals(a, b); //false
```

- strings may be large. So making it a reference type improves memory efficiency (through interning) and performance (by passing references instead of copying the entire string).
