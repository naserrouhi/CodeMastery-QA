# Q1-17: Explain access modifiers

    - They are keywords that define the accessibility of classes, methods, properties, and other members.
    - They help to enforce encapsulation and security in object-oriented programming.
    - Security example: another code in other assembly cannot change the balance of a bank account.

1. public --> Anywhere in the project or other projects.
2. private --> Only within the same class.
3. protected --> Within the same class and child classes.
4. internal --> Only within the same assembly (project).
5. protected internal --> Within the same assembly and in child classes in other assemblies.
6. private protected --> Only within the same class and derived classes inside the same assembly.
