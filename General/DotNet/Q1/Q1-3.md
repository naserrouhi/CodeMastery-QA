## Q1-3: What are boxing and unboxing?

- **Boxing**: Converting a value type to a reference type.

- **Unboxing**: Converting a reference type back to a value type.

- Example:

```csharp
int i = 10;          // value type
object o = i;        // boxing (value type to reference type)
int j = (int)o;      // unboxing (reference type to value type)
```

Boxing and unboxing involve memory allocation and copying, so they should be avoided in performance-critical code.
