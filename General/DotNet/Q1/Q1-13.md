# Q1-13: Explain types of type casting.

1. Implicit Casting

    - It happens automatically when you convert a smaller type to a larger type.

```csharp
int x = 10;
long y = x;
```

2. Explicit Casting

   - You have to manually convert a larger type to a smaller type.
   - It will throw exception if casting is not possible.

```csharp
double x = 9.99;
var y = (int)x;
Console.WriteLine(y); //9
```

   - Literal suffixes:

     - d, D → double
     - f, F → float
     - m, M → decimal
     - l, L → long
     - u, U → uint
     - ul, UL → ulong

```csharp
double a = 10.5d;
```

1. Safe Type Casting

    - The "as" keyword allows you to safely cast between nullabale types.
    - If the cast fails, it will return null.

```csharp
object obj = "Hello, World!";
var str = obj as string?;
```

4. Type Checking

    - The "is" keyword is used to check whether a varivale is of a particular type, before casting it.

```csharp
object obj = "Hello, World!";

if (obj is string str)
    Console.WriteLine(str);
```

5. Safe Conversion

    - If the conversion is not valid, it will throw an exception.

```csharp
var str = "123";
var num = Convert.ToInt32(str);
```

6. Boxing and Unboxing

    - Boxing is used when you need to store a value type in a reference type (e.g., an ArrayList that holds objects).

```csharp
var x = 10;
object obj = x;  //Boxing
int y = (int)obj;  //Unboxing
```
