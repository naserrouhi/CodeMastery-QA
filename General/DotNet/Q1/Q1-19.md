## Q1-19: What's the difference between positional and regular records?

1. They have different syntax in defining an using them.

```csharp
public record Person
{
    public string FirstName { get; init; }
    public string LastName { get; init; }

    public Person(string firstName, string lastName)
    {
        FirstName = firstName;
        LastName = lastName;
    }
}

var person = new Person { FirstName = "John", LastName = "Doe" };
```

```csharp
public record Person(string FirstName, string LastName);

var person = new Person("John", "Doe");
```

2. Regular records can be mutale by using set instead of set for properties (not recommended), but positional records are always immutale.  

3. Unlike regular records, the compiler automatically generates a deconstructor for positional records. 

```csharp
var (firstName, lastName) = person;
Console.WriteLine($"First Name: {firstName}, Last Name: {lastName}");
```

- Both of them can have methods.

```csharp
public record Person
{
    public string Name { get; init; }
    public int Age { get; init; }

    public Person(string name, int age)
    {
        Name = name;
        Age = age;
    }

    public string Greet() => $"Hello, my name is {Name}!";
}
```

```csharp
public record Person(string Name, int Age) 
{
    public string Greet() => $"Hello, my name is {Name}!";
}
```
