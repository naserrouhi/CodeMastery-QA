## Q1-1: What are value types?

- Value types directly store their data in the variable itself.

- Stored on the **stack**.

- **Examples**:
  - Primitive types: `int`, `float`, `double`, `bool`, `char`
  - Structs: `DateTime`, `TimeSpan`
  - Enums

- When you assign a value type variable to another, a **copy** of the value is created. Changes to one variable do not affect the other.

- When value types are a part of a reference type like class or list it stores in the heap.

- All the value types except custom structs are immutable.

- All the value types are compare by value.

- All primitive types are alias for their structs. (int --> System.Int32)

- DateTime and Guid are structs. They are immutable by design.
