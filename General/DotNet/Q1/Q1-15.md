# Q1-16: How .NET Handles Serialization and Deserialization?

- Request body deserialization and response body serialization are automatically handled by the ASP.NET Core framework.
- The default library for these operations is System.Text.Json.
- You can switch to Newtonsoft.Json by configuring it in your project.
- By default, System.Text.Json only serializes and deserializes properties, not fields.
