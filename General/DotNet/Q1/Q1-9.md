# Q1-9: What are RAM areas?

RAM (Random Access Memory) contains:

- Stack (local variables, method calls)

  - Every thread has its own stack.

- Heap (objects, dynamically allocated memory)

  - It is shared between threads.

- Code segment (program instructions):

  - It contains compiled codes of the program and it is readonly.

  - Methods are stored in the code segment of memory. they don't have references in the stack.

- Data segment (global/static variables)

- Memory-mapped areas (hardware, I/O)

- Thread-specific storage (for multi-threaded programs)

  - it stores thread local variables.
