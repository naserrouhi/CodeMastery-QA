# Q2: What are reference types?

- Reference types store a reference (memory address) to the actual data.

- The value stores on the **heap**, but the reference stores on the **stack**.

- **Examples**:
  - Classes: `string`, `object`
  - Arrays: `int[]`
  - Delegates: `Action`, `Func`

- When you assign a reference type variable to another, both variables point to the **same memory location**. Changes to one variable affect the other. (Same value, different references)

- `string` is a reference type but behaves like a value type.
