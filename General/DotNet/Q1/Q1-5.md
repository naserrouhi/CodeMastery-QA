## Q1-5: What does GC do?

- When an object is no longer referenced (not used by the program), it becomes garbage.

- The GC removes the garbage objects from the heap.

- Example

```csharp
void Example() {s
    Person p = new Person(); // Object created in heap
    p = null;  // No reference to object → Garbage collector will clean it
}
```

- It Automatically runs when needed.

    1. Low Memory Situation
    2. Too Many Objects Created
    3. When System Is Idle

- It can be manually triggered using GC.Collect(); (not recommended unless necessary).

- It Prevents memory leaks.
