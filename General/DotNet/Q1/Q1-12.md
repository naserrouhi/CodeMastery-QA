## Q1-12: What's the difference between pass by reference and pass by value?

1. Pass by Value

    - Value type: A copy of the value is passed. Changes do not affect the original.
    - Reference type: A copy of the reference is passed, so the method can modify the object, but cannot change the reference itself.

2. Pass by Reference

    - Value type: The memory address of the variable is passed, so changes affect the original value.
    - Reference type: The actual reference is passed, so the method can modify the object or assign a new object to the reference.

    1. ref: the variable need to be initialized before calling the method.
    2. out: The method must assign a value before returning.

```csharp
public static void Main()
{
	var person = new Person { Name = "Alice" };
		
    ReplacePerson1(ref person);
    Console.WriteLine(person.Name); //Charlie1

    ReplacePerson2(person);
    Console.WriteLine(person.Name); //Charlie1
		
    ChangeName1(ref person);
    Console.WriteLine(person.Name); //Charlie3
		
    ChangeName2(person);
    Console.WriteLine(person.Name); //Charlie4
}
	
static void ReplacePerson1(ref Person p)
{
    p = new Person { Name = "Charlie1" };
}

static void ReplacePerson2(Person p)
{
    p = new Person { Name = "Charlie2" };
}
	
static void ChangeName1(ref Person p)
{
    p.Name = "Charlie3";
}

static void ChangeName2(Person p)
{
    p.Name = "Charlie4";
}
```
