##


- ToString(): This method doesn't relate to equality.

- Equal(): It just compares the reference of objects by default.

- GetHashCode():

    - When we want to override Equal method we should override GetHashCode() method too. because this method is used in hash-based collections.

- GetAtomcValues:

    - It is not a built-in method in C#
    - It is used for types that need to implement value-based equality.
    - It avoids repeating the logic for comparing individual fields in both Equals() and GetHashCode().

```csharp
public record Person(string Name, int Age)
{
    public IEnumerable<object> GetAtomicValues()
    {
        yield return Name; // Atomic value 1
        yield return Age;  /Aoi au 
    }

    // Optionally, override Equals and GetHashCode using the atomic values
    public override bool Equals(object? obj)
    {
        if (obj is Person other)
        {
            // Compare the atomic values (Name and Age)
            return GetAtomicValues().SequenceEqual(other.GetAtomicValues());
        }
        return false;
    }

    public override int GetHashCode()
    {
        // Combine the hash codes of the atomic values (Name and Age)
        return HashCode.Combine(GetAtomicValues());
    }
}

class Program
{
    static void Main()
    {
        var person1 = new Person("Alice", 30);
        var person2 = new Person("Alice", 30);
        var person3 = new Person("Bob", 25);

        Console.WriteLine(person1.Equals(person2));  // Output: True
        Console.WriteLine(person1.Equals(person3));  // Output: False

        Console.WriteLine(person1.GetHashCode());    // Output: HashCode for Alice, 30
        Console.WriteLine(person2.GetHashCode());    // Output: Same hash code as person1
        Console.WriteLine(person3.GetHashCode());    // Output: Different hash code for Bob, 25
    }
}
```
