## Q1-16: What are required, init and default?

1. required

    - It ensures that a property must be initialized when an object is created.
    - It cannot be used for fields.

```csharp
var p = new Person(); //Error
var p2 = new Person { Name = "John" }; //OK
```

2. default

    - It gives a default value to a variable, field, or property based on its type.
    - Can be used in generics: default(T)
    - The default! tells the compiler not to issue a warning even if default is assigned to a non-nullable type.
    - The default value if string is null.

```csharp
public class Example
{
    public string Name { get; set; } = default!; //No Warning
}

var ex = new Example();
Console.WriteLine(ex.Name); //NULL
```

3. init

    - It only allows setting a property during initialization.
    - Helps in creating immutable objects.
    - Records use init by default for immutability.

```csharp
public class UserDto
{
    public required string Email { get; init; }
}

var user = new UserDto { Email = "test@example.com" };
user.Email = "new@example.com"; // Error!
```
