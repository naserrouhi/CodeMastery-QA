# Q7-2: How do you build a basic retrieval-augmented generation (RAG) pipeline?

- RAG = Retrieval-Augmented Generation
- It enhances LLMs (e.g., GPT-4) by retrieving relevant knowledge from a database before generating a response — giving LLMs access to custom or private data.

- RAG Architecture

```plaintext
[User Query] ──► [Embed Query] ──► [Vector DB Search] ──► [Retrieve Context]
                                   ↓
                        [Relevant Docs as Prompt Input]
                                   ↓
                          [LLM (e.g. GPT-4)] ──► Response
```

1. Chunk and Embed Your Data

   - Split your documents into chunks (e.g., 500–1000 tokens), then convert them into embeddings using a model like OpenAI, Cohere, or SentenceTransformers.

```js
// Example: Using OpenAI API
const embedding = await openai.createEmbedding({
  input: "This is one chunk of your docs.",
  model: "text-embedding-3-small",
});
```

2. Store Embeddings in a Vector Database

   - Use a vector DB like Pinecone, Qdrant, Weaviate, or FAISS.

```js
// Upsert into Pinecone
pinecone.upsert({
  id: "chunk1",
  vector: embedding,
  metadata: { source: "faq.pdf", text: "..." },
});
```

3. Embed User Query

   - At runtime, embed the user’s question the same way.

```js
const userEmbedding = await openai.createEmbedding({
  input: "What are your refund policies?",
  model: "text-embedding-3-small",
});
```

4. Search Vector DB for Similar Chunks

   - Query the vector DB for the most similar documents to the question.

```js
const results = await pinecone.query({
  vector: userEmbedding,
  topK: 3,
});
```

5. Build Prompt with Retrieved Context

   - Insert the retrieved documents into the prompt along with the user query.

```text
"You are a helpful assistant.

Here is some context:
---
[doc 1]
[doc 2]
[doc 3]
---

Answer this question:
What is your refund policy?"
```

6. Generate Answer with LLM

   - Use OpenAI or another LLM API to generate a response based on the prompt with context.

```js
const response = await openai.chat.completions.create({
  model: "gpt-4",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: fullPrompt },
  ],
});
```

- Tools Often Used in RAG

| Layer           | Tools                       |
| --------------- | --------------------------- |
| Embedding       | OpenAI, Cohere, HuggingFace |
| Vector Database | Pinecone, FAISS, Qdrant     |
| Chunking        | LangChain, custom logic     |
| LLM Inference   | OpenAI, Anthropic, Mistral  |
| Frameworks      | LangChain, LlamaIndex       |

- Real Example: Use Case

  - Let’s say you upload 100 company policies (PDFs).
  - RAG helps you answer:
    - "Can I take parental leave if I joined 3 months ago?"
    - ...even if the base LLM doesn’t know your company policy.
