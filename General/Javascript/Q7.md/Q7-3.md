# Q7-3: What is tokenization in the context of LLMs, and how do you optimize cost?

- Tokenization is the process of breaking text into smaller units — called tokens — that an LLM can understand.

- Tokens are not words.

- A token might be:
  - a whole word (e.g., `"hello"`)
  - part of a word (e.g., `"com" + "puter"`)
  - or just punctuation (e.g., `"."`, `","`)

- Example (GPT-3.5 tokenizer):

`"ChatGPT is awesome!"` → `["Chat", "G", "PT", " is", " awesome", "!"]` → 6 tokens

- Why Tokenization Affects Cost

  - LLMs like OpenAI’s GPT charge per token — for both:
    - Prompt tokens (your input)
    - Completion tokens (the response)

- Example:

  - Model: GPT-4-turbo
  - Price: \$0.01 per 1,000 prompt tokens
  - Your prompt = 2,000 tokens → \$0.02

- How to Optimize Token Usage (and reduce cost)

| Tip                                 | Description                                                                                      |
| ----------------------------------- | ------------------------------------------------------------------------------------------------ |
| 1. Summarize Context                | Use shorter or summarized context in prompts (especially in RAG pipelines).                      |
| 2. Avoid Redundant System Prompts   | Don’t repeat system instructions across all messages unless needed.                              |
| 3. Use Compact Format               | Replace verbose JSON or HTML with compact versions.                                              |
| 4. Prune Retrieved Docs             | In RAG, retrieve fewer and smaller documents. Chunk smartly (e.g., \~500 tokens).                |
| 5. Use Tokenizers to Pre-check Size | Use tools like `tiktoken` or `@dqbd/tiktoken` in Node.js to measure token size before sending.   |
| 6. Set Max Tokens                   | Use `max_tokens` to limit output length.                                                         |
| 7. Fine-tune When Repeating Prompts | Fine-tuning can reduce repetitive prompt length if you're sending the same structure repeatedly. |

- Tools to Count Tokens

  - OpenAI Tokenizer Tool

  - Node.js:

  ```bash
  npm install @dqbd/tiktoken
  ```

  ```js
  const { encoding_for_model } = require("@dqbd/tiktoken");
  const enc = encoding_for_model("gpt-3.5-turbo");
  const tokens = enc.encode("Hello, how are you?");
  console.log(tokens.length); // → token count
  ```
