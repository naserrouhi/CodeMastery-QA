# Q6-2: How do you handle user data to ensure GDPR compliance?

| Principle                           | What It Means                                       | How to Handle It in Your App                                                                      |
| ----------------------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| Lawfulness, Fairness & Transparency | Collect data only with user consent and explain why | Use clear privacy policies and consent pop-ups. Log user consent.                                 |
| Data Minimization                   | Collect only necessary data                         | Avoid storing extra personal info. Only ask what you need.                                        |
| Purpose Limitation                  | Use data only for declared purpose                  | Define and stick to clear purposes in your privacy policy.                                        |
| Accuracy                            | Keep data accurate and up-to-date                   | Allow users to update their data easily. Validate input.                                          |
| Storage Limitation                  | Don’t keep data longer than needed                  | Implement data retention policies and auto-delete old data.                                       |
| Integrity and Confidentiality       | Protect data from unauthorized access or breaches   | Use encryption at rest & in transit (HTTPS, DB encryption). Use access control and secure coding. |
| Accountability                      | Be able to prove compliance                         | Keep audit logs, data processing records, and respond to data requests.                           |

- Practical Steps in a MERN Stack App

  1. User Consent & Privacy Policy

     - Show explicit consent forms before data collection.
     - Log consent with timestamps.

  2. Data Access & Portability

     - Provide API or UI for users to:
       - View their personal data
       - Download their data in common format (JSON, CSV)

  3. Data Rectification & Deletion (Right to be Forgotten)

     - Implement endpoints for users to update or delete their data.
     - When deleting, remove from DB and backups (as much as possible).

  4. Data Encryption

     - Use HTTPS/TLS everywhere.
     - Encrypt sensitive fields in MongoDB (e.g., using Mongoose field-level encryption or app-level encryption).
     - Hash passwords with bcrypt or Argon2.

  5. Access Controls

     - Enforce strict authentication and authorization.
     - Limit who in your team can access personal data.

  6. Data Breach Response

     - Monitor logs for unusual activity.
     - Prepare a process to notify users and authorities within 72 hours if breach occurs.

  7. Third-Party Compliance

     - Ensure 3rd party services (analytics, email) comply with GDPR.
     - Have Data Processing Agreements (DPAs) in place.

- Tools & Libraries That Help

  - express-gdpr middleware for consent handling.
  - mongoose-field-encryption for encrypting Mongo fields.
  - Helmet for secure headers.
  - Winston/Logrotate for logging audit trails.
