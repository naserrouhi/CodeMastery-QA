# Q3-2: What are the main considerations when building an Electron app, and how do you ensure security?

- Core Considerations:

  1. Architecture

      - Main Process: Runs Node.js, controls windows, file system, system access.
      - Renderer Process: Runs in Chromium, renders UI (like a browser tab).
      - Communicate between them via IPC (Inter-Process Communication).

  2. Performance

      - Avoid heavy work in the main thread.
      - Use Worker Threads or spawn child processes for CPU-intensive tasks.
      - Minimize memory usage (especially large images, data in memory).

  3. Cross-Platform Support

      - Use `path`, `os`, and other Node APIs carefully.
      - Test on Windows, macOS, and Linux.

  4. Packaging

      - Use `electron-builder` or `electron-forge` to package the app.
      - Sign your binaries for macOS (notarization) and Windows (code signing).

- Security Best Practices

  1. Disable Node.js Integration in the Renderer

```js
webPreferences: {
  nodeIntegration: false,
  contextIsolation: true,
  enableRemoteModule: false
}
```

  2. Use `contextBridge` for Safe IPC

     - Instead of exposing Node.js APIs directly:

```js
// preload.js
const { contextBridge, ipcRenderer } = require('electron');

contextBridge.exposeInMainWorld('api', {
  sendMessage: (msg) => ipcRenderer.send('message', msg),
});
```

  3. Avoid `eval`, `new Function()`, or untrusted content

     - Never load remote content with `loadURL()` from external sources.
     - Use `loadFile()` or serve trusted local content.

  4. Use a Content Security Policy (CSP)

     - Define a strong CSP in your HTML header:

```html
<meta http-equiv="Content-Security-Policy" content="default-src 'self'; script-src 'self';">
```

  5. Sanitize User Input

     - If you accept user input that could be rendered (like Markdown), sanitize it before displaying to prevent XSS.

  6. Auto-Update Securely

     - If you use auto-updates:
       - Serve updates over HTTPS.
       - Verify file integrity (e.g., checksum or signing).

  7. Keep Dependencies Updated

     - Regularly scan your dependencies for vulnerabilities using:

```bash
npm audit
```

- Example: Secure Window Setup

```js
const win = new BrowserWindow({
  width: 800,
  height: 600,
  webPreferences: {
    preload: path.join(__dirname, 'preload.js'),
    nodeIntegration: false,
    contextIsolation: true,
    enableRemoteModule: false,
  },
});
```

- Key Security Checklist

| Security Measure                            |
| ------------------------------------------- |
| Disable Node integration in renderer        |
| Use `contextBridge` + preload for safe IPC  |
| Load only local content                     |
| Define strict Content Security Policy       |
| Sanitize all user-generated content         |
| Use HTTPS and verify signatures for updates |
| Keep dependencies clean and audited         |
