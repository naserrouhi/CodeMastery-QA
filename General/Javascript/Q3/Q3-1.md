# Q3-1: How do you implement real-time features using WebSockets in a MERN stack application?

1. Install Required Libraries

```bash
npm install socket.io
npm install socket.io-client
```

2. Server-Side Setup (Node.js + Express)

```js
// server.js or app.js
const express = require('express');
const http = require('http');
const { Server } = require('socket.io');

const app = express();
const server = http.createServer(app);

// Enable CORS for Socket.IO
const io = new Server(server, {
  cors: {
    origin: 'http://localhost:3000', // React frontend
    methods: ['GET', 'POST'],
    credentials: true,
  },
});

// Handle connection
io.on('connection', (socket) => {
  console.log('🔌 New client connected: ', socket.id);

  socket.on('sendMessage', (msg) => {
    console.log('📩 Message received:', msg);
    io.emit('receiveMessage', msg); // Broadcast to all clients
  });

  socket.on('disconnect', () => {
    console.log('❌ Client disconnected: ', socket.id);
  });
});

server.listen(5000, () => console.log('Server running on port 5000'));
```

3. Client-Side Setup (React)

```bash
npm install socket.io-client
```

```js
// ChatComponent.jsx
import { useEffect, useState } from 'react';
import { io } from 'socket.io-client';

const socket = io('http://localhost:5000'); // Connect to backend

export default function ChatComponent() {
  const [message, setMessage] = useState('');
  const [messages, setMessages] = useState([]);

  useEffect(() => {
    socket.on('receiveMessage', (msg) => {
      setMessages((prev) => [...prev, msg]);
    });

    return () => socket.off('receiveMessage');
  }, []);

  const sendMessage = () => {
    socket.emit('sendMessage', message);
    setMessage('');
  };

  return (
    <div>
      <ul>
        {messages.map((m, i) => (
          <li key={i}>{m}</li>
        ))}
      </ul>
      <input value={message} onChange={(e) => setMessage(e.target.value)} />
      <button onClick={sendMessage}>Send</button>
    </div>
  );
}
```

4. Use Cases

   - Chat apps
   - Live notifications
   - Collaborative tools (e.g., Google Docs)
   - Stock/crypto price updates
   - Real-time dashboards

5. Security Considerations

   - Authenticate users using token-based middleware (e.g., JWT).
   - Rate limit events to prevent spam.
   - Handle disconnects and reconnects gracefully.
   - For large scale: use Redis adapter to share socket state across multiple server instances.

- MongoDB Integration

  - Save real-time data to MongoDB inside your Socket.IO event handler:

```js
socket.on('sendMessage', async (msg) => {
  await MessageModel.create({ text: msg, userId: socket.userId });
  io.emit('receiveMessage', msg);
});
```
