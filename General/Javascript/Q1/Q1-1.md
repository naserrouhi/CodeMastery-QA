# Q1-1: How does the MERN stack work together in a typical full-stack application?

1. MongoDB (Database)

    - Stores your application data as JSON-like documents (BSON).
    - Example: A `users` collection might store documents like.
    `{ "_id": 1, "name": "Naser", "email": "naser@example.com" }`

2. Express.js (Backend Framework)

    - A lightweight framework that runs on Node.js to handle HTTP requests.

3. React (Frontend)

    - Renders the UI in the browser, using components and state.
    - Makes HTTP requests to the Express backend to get/send data.
    - React runs in the browser and updates the UI dynamically without full-page reloads.

4. Node.js (Runtime)

    - Executes the JavaScript server-side logic (where Express runs).
    - Bridges the frontend and the database—processing requests from React, querying MongoDB, and returning results.

- Flow Example:

    1. User opens the app → React renders UI.
    2. React makes a request to Express: `GET /api/users`
    3. Express handles it using Node.js → Queries MongoDB.
    4. MongoDB returns data → Express sends JSON back to React.
    5. React displays the data in the browser.
