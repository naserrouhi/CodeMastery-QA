# Q1-8: Describe your process for implementing a responsive, mobile-first UI.

1. Mobile-First Mindset (Start Small)

    - I start with mobile layout first using a base font size, single column, full-width elements.
    - Then I progressively enhance the UI for larger screens using media queries or responsive utilities (like Tailwind, Bootstrap).

2. Use a CSS Framework or Utility-First Approach

    - I often use Tailwind CSS or CSS Modules for clean, maintainable styles.
    - Tailwind’s mobile-first breakpoints (e.g., `sm`, `md`, `lg`) make it easy to layer styles.

```tsx
{/* Example with Tailwind */}
<div className="p-4 text-sm sm:text-base md:text-lg lg:text-xl">
  Responsive text
</div>
```

3. Use Flexbox & Grid Layouts

    - I rely heavily on CSS Flexbox and Grid for layout structure.
    - This ensures elements stack vertically on small screens and shift to columns or rows on larger screens.

```css
/* Example with plain CSS */
.container {
  display: flex;
  flex-direction: column;
}

@media (min-width: 768px) {
  .container {
    flex-direction: row;
  }
}
```

4. Fluid Typography and Spacing

    - I use `rem` or `em` for font sizes and spacing instead of `px` to keep things scalable.
    - I also set max widths (`max-w-screen-md`, etc.) to prevent content from stretching on large screens.

5. Responsive Images and Media

    - I use the `picture` tag or `srcset` for responsive images.
    - In Next.js, I use the built-in `<Image />` component which handles responsive images automatically.

6. Viewport Meta Tag

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
```

7. Test on Real Devices and Emulators

    - I use browser dev tools, mobile emulators, and tools like [Responsively App](https://responsively.app/) to preview across breakpoints.

8. Component Isolation

    - I build small, reusable components with props for responsive behavior.
    - I avoid hardcoding layout in pages.

- Tools:

    - Tailwind CSS – mobile-first utility classes
    - Figma – responsive design previews
    - React Testing Library – test responsive behavior
    - Next.js Image component – optimized media
    - Lighthouse – performance & responsiveness checks

- Common Mistakes:

| Mistake                   | Fix                                           |
| ------------------------- | --------------------------------------------- |
| Designing desktop-first   | Always start from smallest screen             |
| Using `px` for everything | Use `rem`, `%`, or Tailwind classes           |
| Ignoring image sizes      | Use responsive images (`srcset`, `<Image />`) |
| Overusing media queries   | Use utility classes or layout systems instead |
