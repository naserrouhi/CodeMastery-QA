# Q1-5: Explain how you manage component state and global state in React.

- Component (Local) State:

    - State that is only relevant to a single component (e.g., form input, modal visibility).
    - Use `useState()` or `useReducer()` directly in the component.

- Example:

```tsx
function LoginForm() {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [error, setError] = useState(null);

  return (
    <form>
      <input value={email} onChange={(e) => setEmail(e.target.value)} />
      <input type="password" value={password} onChange={(e) => setPassword(e.target.value)} />
      {error && <div>{error}</div>}
    </form>
  );
}
```

- Global State:

    - State shared across multiple components or pages, such as:

        - User authentication
        - Theme or language settings
        - Shopping cart, dashboard data, etc.

- Common Tools for Global State:

| Tool                  | Use Case                                  | Notes                                                        |
| --------------------- | ----------------------------------------- | ------------------------------------------------------------ |
| React Context         | Light global state (auth, theme)          | Avoid for complex data or frequent updates                   |
| Redux / Redux Toolkit | Complex, structured app-wide state        | Centralized, predictable, scalable                           |
| Zustand               | Lightweight global state                  | Minimal boilerplate, ideal for most cases                    |
| Recoil / Jotai        | Alternative state libraries               | Recoil: Graph-based; Jotai: atomic design                    |
| React Query / SWR     | Server state (caching, fetching, syncing) | Not for managing local/global state, but complements it well |

- Redux Toolkit:

    - Best for managing complex, app-wide state like user authentication, UI flags, or local caches.

- React Query (Server State):

    - Best for fetching, caching, and syncing data from the backend (e.g., user profile, products).


- Example with React Context:

```tsx
// auth-context.tsx
const AuthContext = createContext(null);

export function AuthProvider({ children }) {
  const [user, setUser] = useState(null);
  const login = (userData) => setUser(userData);
  const logout = () => setUser(null);

  return (
    <AuthContext.Provider value={{ user, login, logout }}>
      {children}
    </AuthContext.Provider>
  );
}

// usage in component
const { user } = useContext(AuthContext);
```

- Example with Zustand:

```tsx
const useAuthStore = create((set) => ({
  user: null,
  login: (user) => set({ user }),
  logout: () => set({ user: null }),
}));

const user = useAuthStore((state) => state.user);
```

- Example with Redux Toolkit: 

```ts
// store/authSlice.ts
import { createSlice } from '@reduxjs/toolkit';

const initialState = {
  user: null,
};

const authSlice = createSlice({
  name: 'auth',
  initialState,
  reducers: {
    login: (state, action) => {
      state.user = action.payload;
    },
    logout: (state) => {
      state.user = null;
    },
  },
});

export const { login, logout } = authSlice.actions;
export default authSlice.reducer;
```

```ts
//Configure Store

// store/index.ts
import { configureStore } from '@reduxjs/toolkit';
import authReducer from './authSlice';

export const store = configureStore({
  reducer: {
    auth: authReducer,
  },
});

export type RootState = ReturnType<typeof store.getState>;
export type AppDispatch = typeof store.dispatch;
```

```tsx
//Usage in Component

// LoginButton.tsx
import { useDispatch, useSelector } from 'react-redux';
import { login } from '../store/authSlice';

function LoginButton() {
  const dispatch = useDispatch();
  const user = useSelector((state) => state.auth.user);

  return (
    <button onClick={() => dispatch(login({ name: 'Naser' }))}>
      {user ? `Hello, ${user.name}` : 'Login'}
    </button>
  );
}
```

- Example with React Query:

```ts
//Setup

// api/userApi.ts
import axios from 'axios';

export const getUserProfile = () => axios.get('/api/user').then(res => res.data);
```

```tsx
// Usage in Component

// Profile.tsx
import { useQuery } from '@tanstack/react-query';
import { getUserProfile } from '../api/userApi';

function Profile() {
  const { data, isLoading, error } = useQuery({
    queryKey: ['userProfile'],
    queryFn: getUserProfile,
  });

  if (isLoading) return <p>Loading...</p>;
  if (error) return <p>Error!</p>;

  return <div>Welcome, {data.name}</div>;
}
```

- When to Use Which?

| Use Case                         | Use This         |
| -------------------------------- | ---------------- |
| Auth status                      | Redux or Zustand |
| UI flags (sidebar open)          | Redux or Zustand |
| Data from backend                | React Query      |
| Form input state                 | useState         |
| Cached API data (e.g. user list) | React Query      |

- Common Mistakes (Interview Trick)

    - Using Context for large or frequently updated data (causes performance issues).
    - Not separating server state (fetched from backend) from local/global state.
    - Overusing Redux when something simpler (like Zustand or Context) would do.
